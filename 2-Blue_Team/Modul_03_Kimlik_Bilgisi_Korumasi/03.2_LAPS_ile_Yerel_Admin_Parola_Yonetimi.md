## 1. Kavramsal Temel — Neden Var?

Kurumsal ortamların en eski, en ölümcül alışkanlığı: **her makinede aynı yerel yönetici (Administrator) parolası.** Bir imaj (golden image) hazırlanır, binlerce makineye kopyalanır — hepsinin yerel admin parolası aynıdır. Saldırgan tek bir makineden bu hash'i çalarsa ([03.1](./03.1_Credential_Guard_ve_LSASS_Korumasi.md)), **Pass-the-Hash** ile aynı parolaya sahip **tüm** makinelere yayılır. Buna **lateral movement via shared local admin** denir ve gerçek ihlallerin belkemiğidir.

**LAPS (Local Administrator Password Solution)**, bu zinciri kırar: her makinenin yerel admin parolasını **benzersiz, rastgele, düzenli dönen** bir değere ayarlar ve şifreli olarak AD'de saklar. Makine A'nın parolası çalınsa, makine B'ye yaramaz — yanal hareket **tek makinede** durur.

> **İlke:** Ortak yerel admin parolası = tek noktadan tüm ağın düşmesi. LAPS, "bir makine = bir benzersiz sır" ilkesiyle Pass-the-Hash'in yayılma yarıçapını **1 makineye** indirir.

Windows LAPS (2023+), eski Microsoft LAPS'in yerini alan, AD ve Entra ID'yi yerel destekleyen modern sürümdür. Bu, [Sistem 10.3 Hardening](../../1-Sistem_Yoneticisi/Modul_10_Guvenlik_Yedekleme_ve_Kurtarma/10.3_Hardening_Temelleri.md)'in kimlik katmanının pratik uygulamasıdır.

## 2. Teknik Derinlik

### 2.1 LAPS akışı ve AD saklama

```
   ┌── Her istemci/sunucu ──┐         ┌──────── AD (bilgisayar nesnesi) ────────┐
   │ Windows LAPS ajanı      │         │  msLAPS-Password (şifreli, DPAPI-NG)     │
   │ ① rastgele parola üret  │────────►│  msLAPS-PasswordExpirationTime           │
   │ ② yerel admin'e uygula  │  LDAP   │  msLAPS-EncryptedPassword (Entra/AES)    │
   │ ③ AD'ye şifreli yaz      │  (imzalı)│                                          │
   │ ④ süre dolunca ROTASYON │         │  → yalnızca YETKİLİ okur (ACL + audit)   │
   └─────────────────────────┘         └──────────────────────────────────────────┘
        Parola makinede DEĞİL, AD'de; okuma yetkisi delege + LOGLANIR (4662/5136)
```

### 2.2 Şifreleme ve okuma yetkisi (kritik)

Eski LAPS parolayı **düz metin** attribute'ta (`ms-Mcs-AdmPwd`) tutardı — okuma yetkisi olan herkes görürdü. **Windows LAPS**, parolayı **şifreli** (DPAPI-NG, belirli grup/kullanıcıya çözülebilir) saklar; ayrıca **parola geçmişi** ve **DSRM parolası** yönetimini de kapsar. Okuma yetkisi (`Control Access`) yalnızca yetkili gruba delege edilir ve her okuma **denetlenir** (4662).

### 2.3 Saldırgan gözünden LAPS

LAPS'in kendisi bir hedeftir: saldırgan `msLAPS-Password` okuma yetkisini ele geçirirse ([Red M01 keşif](../../3-Red_Team/Modul_01_Kesif_ve_Numaralandirma/)), tüm yerel admin parolalarını okuyabilir. Bu yüzden okuma yetkisi **Tier 0** korumasında olmalı ve okuma olayları izlenmeli (§4).

## 3. Pratik Uygulama

### 3.1 Windows LAPS'i etkinleştir (şema + politika)
```powershell
# AD şemasını Windows LAPS için genişlet (Schema Admin gerekir)
Update-LapsADSchema
# Bilgisayarların kendi parolalarını yazma yetkisi (OU bazlı)
Set-LapsADComputerSelfPermission -Identity "OU=Workstations,DC=corp,DC=local"
```

### 3.2 GPO ile parola politikası
```text
GPO: Computer Config → Administrative Templates → System → LAPS →
   "Configure password backup directory" = Active Directory
   "Password Settings": Length=20, Complexity=Large+Small+Numbers+Special
   "Password age (days)" = 30
   "Post-authentication actions" = Reset password + logoff (oturum sonrası çevir)
```

### 3.3 Parola okuma yetkisini delege et + denetle
```powershell
# Sadece yetkili gruba okuma yetkisi ver
Set-LapsADReadPasswordPermission -Identity "OU=Workstations,DC=corp,DC=local" `
  -AllowedPrincipals "CORP\Tier1-Admins"
# Yetkili biri parolayı okur (kurtarma senaryosu) — bu okuma 4662 üretir
Get-LapsADPassword -Identity "WKS01" -AsPlainText
```

## 4. Tespit Değeri — Parola Okuma ve Yetki Manipülasyonu

LAPS parolasının okunması **nadir ve hedefli** bir olaydır; anormal okuma = ele geçmiş yetki:

```yaml
# Sigma — LAPS parolasına anormal/toplu erişim
title: LAPS Parola Attribute Okuma (Olasi Kotuye Kullanim)
logsource: { product: windows, service: security }
detection:
  sel:
    EventID: 4662
    Properties|contains: ['ms-Mcs-AdmPwd','msLAPS-Password','msLAPS-EncryptedPassword']
  condition: sel
level: medium
tags: [attack.credential_access, attack.t1552.001]
```
```kql
// KQL — tek principal'ın kısa sürede ÇOK makinenin LAPS parolasını okuması
SecurityEvent
| where EventID == 4662 and ObjectProperties has "msLAPS-Password"
| summarize Makineler=dcount(ObjectName) by SubjectAccount, bin(TimeGenerated, 15m)
| where Makineler >= 10       // 15 dk'da 10+ makine = LAPS harvesting
```

| Sinyal | Event | Anlamı | MITRE |
|--------|-------|--------|-------|
| `msLAPS-Password` okuma | 4662 | Yerel admin parolası alındı | T1552.001 |
| LAPS attribute ACL değişimi | 5136 | Okuma yetkisi genişletildi (yetki abuse) | T1098 |
| Toplu okuma (çok makine) | 4662 hacim | LAPS harvesting | T1078 |

## 5. Doğrulama / Lab

```powershell
# 1) LAPS gerçekten çalışıyor mu? Parola AD'de + rotasyon oluyor mu?
Get-LapsADPassword -Identity "WKS01"    # ExpirationTime gelecekte olmalı
# 2) Benzersizlik testi: iki farklı makinenin parolası FARKLI olmalı
Get-LapsADPassword WKS01 -AsPlainText; Get-LapsADPassword WKS02 -AsPlainText
# 3) Tespit testi: bir parolayı oku → 4662 üretilmeli, §4 kuralı alarm vermeli
# 4) PtH sınırı testi (izole lab): WKS01 yerel admin hash'iyle WKS02'ye
#    bağlanmayı dene → BAŞARISIZ olmalı (parolalar farklı)
```
> **Kanıt:** LAPS'in değeri "iki makinenin farklı parolası" ile somutlaşır; PtH'nin yayılmadığını lab'da göster.

## 7. Güvenlik Notu ve Sık Yapılan Hatalar

- 🔴 **Ortak yerel admin parolası bırakmak:** LAPS olmadan tek hash tüm ağı açar; LAPS bu tek noktayı ortadan kaldırır.
- 🔴 **Eski (düz metin) LAPS attribute'unu korumasız bırakmak:** `ms-Mcs-AdmPwd` okuma yetkisini daralt; mümkünse şifreli Windows LAPS'e geç.
- ⚠️ **LAPS okuma yetkisini geniş delege etmek:** Okuma yetkisi Tier 0/1 sınırında olmalı; herkese açık okuma = tüm yerel admin parolaları açık.
- ⚠️ **DSRM parolasını unutmak:** Windows LAPS DSRM parolasını da yönetebilir; DC kurtarma için kritik ([Sistem 10.1](../../1-Sistem_Yoneticisi/Modul_10_Guvenlik_Yedekleme_ve_Kurtarma/10.1_NTDS_ve_ntdsutil.md)).
- 🔍 **İzleme ipucu:** Tek hesabın kısa sürede onlarca makinenin LAPS parolasını okuması, **LAPS harvesting**'tir — meşru kurtarmada tek makine okunur.
