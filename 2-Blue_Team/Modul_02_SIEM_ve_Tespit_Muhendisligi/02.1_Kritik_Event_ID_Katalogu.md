## 1. Kavramsal Temel — Neden Var?

[Blue M01](../Modul_01_Gorunurluk_ve_Log_Yonetimi/) telemetriyi topladı; ama binlerce Event ID içinde **hangileri saldırıyı ele verir?** Tespit mühendisliğinin ilk adımı, gürültü denizinde **yüksek sinyalli olayları** tanımaktır. Bir Event ID tek başına nadiren "saldırı" der; anlam **bağlamda** (context), **korelasyonda** ve **anomalide** doğar. Örneğin 4769 (Kerberos servis bileti) her gün on binlerce kez üretilir — ama **RC4 şifreleme + anormal hesap + çok sayıda SPN** birleşince Kerberoasting'dir.

Bu dosya, [Sistem 10.4](../../1-Sistem_Yoneticisi/Modul_10_Guvenlik_Yedekleme_ve_Kurtarma/10.4_Denetim_ve_Uyumluluk.md)'teki katalog özetini **tespit odaklı** derinleştirir: her olayı **hangi saldırıya**, **hangi bağlamda**, **hangi Red tekniğine (MITRE)** bağlayarak. [02.2](./02.2_Sigma_Elastic_Splunk_Kural_Yazimi.md)'de bunlar kurala dönüşür.

> **İlke:** Event ID = harf; korelasyon = kelime; bağlam = cümle. Tespit, tek olayı değil, olay **dizisini** okur.

## 2. Teknik Derinlik

### 2.1 Olay ailelerine göre katalog (kill-chain eşlemeli)

```
  KEŞİF          İLK ERİŞİM       KİMLİK HIRSIZ.    YANAL HAREKET    HAKİMİYET
  ─────          ──────────       ──────────────    ─────────────    ─────────
  4662(SACL)     4625(spray)      4769(Kerberoast)  4624 T3/T10      4662(DCSync)
  5136/5137      4771             4768(AS-REP)      4648(explicit)   4728/4732
  1644(LDAP)     4776(NTLM)       Sysmon10(LSASS)   7045(svc)        1102(temizle)
                                                    Sysmon1(psexec)  4794(DSRM)
```

### 2.2 Kimlik doğrulama olaylarının anatomisi (en kritik alan)

| Event ID | Log | Anlamı | Tespit değeri / bağlam |
|----------|-----|--------|------------------------|
| **4624** | Security | Başarılı oturum | **LogonType** kritik: 3=ağ, 10=RDP, 9=RunAs (overpass) |
| **4625** | Security | Başarısız oturum | Status kodu (`0xC000006A`=parola, `0x18`=kilit) → spray |
| **4768** | Security (DC) | TGT istendi | AS-REP roast: `PreAuthType=0` → [Red M03](../../3-Red_Team/Modul_03_Kimlik_Bilgisi_Erisimi/) |
| **4769** | Security (DC) | TGS istendi | Kerberoast: `TicketEncryptionType=0x17` (RC4) + anormal SPN |
| **4771** | Security (DC) | Kerberos pre-auth başarısız | Spray/brute (`0x18`=yanlış parola) |
| **4776** | Security (DC) | NTLM doğrulama | Eski protokol; relay/pass-the-hash izi |
| **4648** | Security | Explicit cred ile logon | Overpass-the-hash, pivot ("RunAs") |

### 2.3 LogonType — yanal hareketin parmak izi

`4624`'ün **LogonType** alanı, oturumun **nasıl** açıldığını söyler ve yanal hareket tespitinin kalbidir:

| Type | Anlamı | Şüphe bağlamı |
|------|--------|----------------|
| **2** | İnteraktif (konsol) | Normal |
| **3** | Ağ (SMB/WMI) | PtH, dosya paylaşımı erişimi |
| **9** | NewCredentials (RunAs /netonly) | **Overpass-the-Hash** → [Red M04](../../3-Red_Team/Modul_04_Yanal_Hareket/) |
| **10** | RemoteInteractive (RDP) | Yanal RDP, anormal saat |

## 3. Pratik Uygulama

### 3.1 Katalog olaylarını sorgula (Get-WinEvent)
```powershell
# Kerberoast adayı: RC4 (0x17) şifrelemeli TGS istekleri
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4769} |
  Where-Object { $_.Message -match 'Ticket Encryption Type:\s+0x17' -and
                 $_.Message -notmatch 'krbtgt|\$' } |
  Select TimeCreated, @{N='Hizmet';E={($_.Message -split 'Service Name:\s+')[1].Split("`n")[0]}}
```
```powershell
# Password spraying: kısa sürede çok hesaba tek-iki deneme (4625/4771)
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625;
  StartTime=(Get-Date).AddMinutes(-30)} |
  Group-Object { ($_.Message -split 'Account Name:\s+')[2].Split("`n")[0] } |
  Where-Object Count -ge 1 | Measure-Object   # çok sayıda farklı hesap = spray
```

### 3.2 Bağlam zenginleştirme (korelasyon için asset/kimlik)
```text
Ham Event ID'yi anlamlı yapan: hesap tipi (servis/yönetici?), makine rolü
(DC/istemci?), saat (mesai dışı?), coğrafya (imkânsız seyahat?).
→ SIEM'de asset+identity enrichment [Blue M01 · 01.4] ile eşle.
```

## 4. Tespit Değeri — Katalogdan Alarma

```yaml
# Sigma — AS-REP Roasting (pre-auth kapalı hesaba TGT)
title: AS-REP Roasting Belirtisi
logsource: { product: windows, service: security }
detection:
  sel: { EventID: 4768, PreAuthType: '0' }        # 0 = pre-auth yok
  filter: { TicketEncryptionType: '0x12' }         # AES normal
  condition: sel and not filter
level: high
tags: [attack.credential_access, attack.t1558.004]
```

| Saldırı | Ana Event | Ayırt edici bağlam | MITRE | Karşı Red |
|---------|-----------|--------------------|-------|-----------|
| Password Spray | 4625/4771 | Çok hesap × az deneme, kısa pencere | T1110.003 | [Red M02](../../3-Red_Team/Modul_02_Ilk_Erisim_ve_Yerlesme/) |

## 5. Doğrulama / Lab

```powershell
# Kerberoast olayını üret (izole lab): bir SPN'e TGS iste
Add-Type -AssemblyName System.IdentityModel
New-Object System.IdentityModel.Tokens.KerberosRequestorSecurityToken `
  -ArgumentList "MSSQLSvc/db01.corp.local:1433"   # → 4769 (0x17) üretmeli
# Beklenen: §4 Sigma AS-REP/Kerberoast kuralı tetiklenir. Tetiklenmezse
# audit alt kategorisi (01.2) veya RC4 filtresi yanlıştır.
```

## 7. Güvenlik Notu ve Sık Yapılan Hatalar

- 🔴 **Tek Event ID'ye alarm bağlamak:** 4769 tek başına gürültü; RC4 + hesap tipi + hacim korelasyonu olmadan yüzlerce yanlış-pozitif üretir.
- 🔴 **LogonType'ı görmezden gelmek:** 4624 Type 3/9/10 ayrımı yapılmadan yanal hareket görünmez.
- ⚠️ **DC-only olayları istemcide aramak:** 4768/4769/4662 yalnızca DC'de üretilir; kaynağı DC Security log'u olmalı.
- ⚠️ **Status kodlarını atlamak:** 4625/4771'de `0xC000006A` vs `0x18` vs `0xC0000234` ayrımı (yanlış parola / kilit) spray'i kilitlemeden ayırır.
- 🔍 **İzleme ipucu:** **4662**'de replikasyon uzantılı hakları (`DS-Replication-Get-Changes`) içeren erişim, DCSync'in kesin izidir — SACL şart ([Blue 01.2](../Modul_01_Gorunurluk_ve_Log_Yonetimi/01.2_Advanced_Audit_Policy.md)).
