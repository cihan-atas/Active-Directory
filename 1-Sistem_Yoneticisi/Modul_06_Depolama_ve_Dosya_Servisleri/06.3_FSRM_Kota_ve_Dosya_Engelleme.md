# 06.3 — FSRM: Kota, Dosya Engelleme ve Depolama Raporları

> **Modül:** 06 — Depolama ve Dosya Servisleri · **Kol:** Sistem Yöneticisi
> **Ön koşul:** [06.2 — DFS-R Replikasyon](./06.2_DFS_R_Replikasyon.md) · **Sonraki:** [06.4 — SYSVOL ve GPO Dağıtımı](./06.4_SYSVOL_ve_GPO_Dagitimi.md)

## 1. Kavramsal Temel — Neden Var?

Dosya sunucuları kontrolsüz büyür: kullanıcılar sınırsız veri yığar, film/ISO gibi istenmeyen dosyalar paylaşımları doldurur, ve en tehlikelisi — **ransomware** dosyaları şifreleyip fidye notları bırakır. Bunları yönetmek için Windows'un **File Server Resource Manager (FSRM)** rolü vardır:

1. **Quotas (Kotalar):** Klasör/birim bazında alan sınırı.
2. **File Screening (Dosya Engelleme):** Belirli dosya türlerinin (uzantıların) yazılmasını engelleme/uyarma — istenmeyen içerik *ve* ransomware azaltma.
3. **Storage Reports:** Kim ne kadar yer kullanıyor, hangi dosya türleri, yinelenenler.
4. **File Management Tasks:** Otomatik dosya sınıflandırma/taşıma/silme.

> **Güvenlik açısı:** File Screening, FSRM'i sadece bir "disk yönetim aracı" olmaktan çıkarıp bir **ransomware azaltma katmanı** haline getirir — bilinen fidye notu adlarını/uzantılarını yazma anında engelleyip yöneticiyi uyarabilir. Bu yüzden Blue Team ile doğrudan kesişir → [Blue M10](../../2-Blue_Team/Modul_10_Olay_Mudahalesi_DFIR_ve_Kurtarma/).

## 2. Teknik Derinlik

### 2.1 Kotalar (Quotas)

- **Hard quota:** Sınıra ulaşınca **yazma engellenir** (aşılamaz).
- **Soft quota:** Sınır aşılabilir ama **uyarı/rapor** üretir (izleme amaçlı).
- **Quota Template:** Standart kota tanımlarını (örn. "200 MB hard") şablonlaştırıp yeni klasörlere otomatik uygular. Şablon güncellenince bağlı kotalar güncellenebilir.
- **Auto-apply quota:** Bir üst klasörün altında oluşturulan her yeni alt klasöre otomatik kota uygular (örn. her kullanıcının home klasörüne 1 GB).
- **Threshold + Action:** %85/%95/%100 gibi eşiklerde e-posta, olay logu, komut çalıştırma veya rapor tetikleme.

### 2.2 File Screening (Dosya Engelleme)

- **File Group:** Uzantı desenleri kümesi (örn. `Executable Files` = `*.exe,*.bat,*.cmd`; `Ransomware notes` = `*.locky,*.crypt,*_HOW_TO_DECRYPT*`).
- **Active screening:** Eşleşen dosyanın yazılmasını **engeller.**
- **Passive screening:** Engellemez ama **uyarır/loglar** (tespit modu).
- **File Screen Exception:** Belirli alt klasörde kurala istisna (örn. IT paylaşımında `.exe`ye izin).
- **Screening Template:** Standart engelleme setlerini şablonlaştırma.

**Ransomware azaltma deseni:** Bilinen ransomware uzantıları/fidye-notu adlarından bir File Group oluştur; **passive** modda tüm paylaşımlara uygula (tespit için); eşleşmede yöneticiyi anında uyar ve olay logla. Bu, erken uyarı ve yayılım sınırlaması sağlar → [Blue M10](../../2-Blue_Team/Modul_10_Olay_Mudahalesi_DFIR_ve_Kurtarma/). (Not: Uzantı-tabanlı engelleme tek başına tam koruma değildir; yedek + davranışsal tespit ile birlikte kullanılır.)

### 2.3 Storage Reports & File Management Tasks

- **Storage Reports:** Büyük dosyalar, en çok yer kullananlar, yinelenen dosyalar, dosya türü dağılımı, quota kullanımı — zamanlanmış rapor.
- **File Management Tasks + Classification:** Dosyaları içerik/özelliğe göre sınıflandırıp (örn. "gizli") otomatik eylem (taşı/süresi dolunca sil/şifrele) uygulama. Uyumluluk (compliance) senaryolarında kullanılır → [Modül 10](../Modul_10_Guvenlik_Yedekleme_ve_Kurtarma/).

## 3. Pratik Uygulama

### FSRM kurulumu ve kota
```powershell
# Install-WindowsFeature FS-Resource-Manager -IncludeManagementTools

# Kota şablonu: 1 GB hard, %85 ve %95 eşiklerinde uyarı
New-FsrmQuotaTemplate -Name "Home-1GB-Hard" -Size 1GB `
  -Threshold (New-FsrmQuotaThreshold -Percentage 85), (New-FsrmQuotaThreshold -Percentage 95)

# Home klasörlerine otomatik kota (her yeni alt klasöre uygula)
New-FsrmAutoQuota -Path "D:\Shares\Home" -Template "Home-1GB-Hard"

# Tek klasöre hard kota
New-FsrmQuota -Path "D:\Shares\Proje" -Template "Home-1GB-Hard"
```

### File screening — ransomware azaltma (passive tespit)
```powershell
# Bilinen ransomware desenlerinden file group
New-FsrmFileGroup -Name "Ransomware-Patterns" `
  -IncludePattern @("*.locky","*.crypt","*.crypto","*.encrypted","*_HOW_TO_DECRYPT*","*DECRYPT_INSTRUCTION*","*.wncry")

# Eşleşmede e-posta + olay logu üreten aksiyon
$act = New-FsrmFmjAction -Type Event -EventType Warning -Body "Olası ransomware dosyası: [Source Io Owner] -> [File Screen Path]"

# Passive screen (engelleme değil, tespit) — tüm paylaşım köküne uygula
New-FsrmFileScreen -Path "D:\Shares" -IncludeGroup "Ransomware-Patterns" -Active:$false -Notification $act
```

### Executable engelleme (aktif) + istisna
```powershell
New-FsrmFileScreen -Path "D:\Shares\Muhasebe" -IncludeGroup "Executable Files" -Active:$true
# IT paylaşımında exe'ye izin (istisna)
New-FsrmFileScreenException -Path "D:\Shares\IT-Araclar" -IncludeGroup "Executable Files"
```

### Depolama raporu
```powershell
New-FsrmStorageReport -Name "BuyukDosyalar" -Namespace "D:\Shares" `
  -ReportType LargeFiles -LargeFileMinimum 500MB -Schedule (New-FsrmScheduledTask -Time "02:00" -Weekly Sunday)
```

## 4. Tasarım İlkeleri (Mimarın Bakışı)

- **Şablonla yönet:** Kota ve screening'i şablonlarla standartla; tek tek klasör ayarı bakımı zorlaştırır.
- **Ransomware screening'i passive başlat:** Önce tespit/uyarı modunda çalıştır (yanlış-pozitif ve iş kesintisini önlemek için), olgunlaştıkça kritik gruplarda aktif engellemeye geç.
- **FSRM tek başına yeterli değil:** Uzantı-tabanlı; ransomware uzantı değiştirir. Yedek ([Modül 10](../Modul_10_Guvenlik_Yedekleme_ve_Kurtarma/)) + EDR + shadow copy ile katmanla → [Blue M10](../../2-Blue_Team/Modul_10_Olay_Mudahalesi_DFIR_ve_Kurtarma/).
- **Eşik aksiyonlarını izlemeye bağla:** Kota/screen olaylarını merkezî logla; erken uyarı değeri yüksek → [Blue M01](../../2-Blue_Team/Modul_01_Gorunurluk_ve_Log_Yonetimi/).

## 6. Güvenlik Notu ve Sık Yapılan Hatalar

- ⚠️ **Aktif engellemeyi test etmeden dağıtmak:** İş dosyalarını yanlışlıkla engelleyip operasyonu kesebilir; passive başla, istisnaları belirle.
- ⚠️ **Hard kotayı home dışında dikkatsiz kullanmak:** Uygulama/servis klasörlerinde beklenmedik yazma hatalarına yol açabilir.
- 🔴 **FSRM'i tek ransomware savunması sanmak:** Uzantı-tabanlı screening kolayca atlatılır (uzantı değiştirme). Katmanlı savunma (yedek + EDR + en az ayrıcalık ACL) şart → [Blue M10](../../2-Blue_Team/Modul_10_Olay_Mudahalesi_DFIR_ve_Kurtarma/).
- 🔒 **Erken uyarı değeri:** Passive ransomware screen, bir şifreleme dalgasının ilk fidye-notu yazımında yöneticiyi uyararak yayılımı erken durdurma şansı verir — düşük maliyetli, yüksek değerli bir kontrol.
- 🔍 **İzleme ipucu:** File screen ihlalleri (FSRM olay logu) ve kısa sürede çok sayıda ihlal (kütle şifreleme işareti) yüksek öncelikli alarmdır → [Blue M02](../../2-Blue_Team/Modul_02_SIEM_ve_Tespit_Muhendisligi/).
